## 2. 必须先拍板的两个决定（草案里没写，但实现已经/将要撞上）

### 决定一：连续场的**颜色面**在导出里怎么表达？

草案 §A 说"几何只有一份"，而实现把它做成**一张栅格**（不是逐格多边形）。两者在导出侧冲突：
SVG 无法表达栅格，只能内联成 data URL —— 而这与仓库既有取舍（`mapPreview` 的 SVG **从不内联图片**，
理由是"导出文件要能脱离你的库打开"、且文件体积可控）**直接对撞**。同时那条测试
「几何只有一份：导出的叠加层图元数与画布计划逐项一致」用"图元数"表达一致性，**栅格面根本无法计入图元数**。

- **(a) 导出内联栅格**：自包含 ✓；代价是文件变大、推翻"SVG 不嵌图"的口径，PNG 侧无影响。
- **(b) 导出时颜色面退回逐格多边形**（纯矢量、小体积）：代价是"几何只有一份"这句承诺
  **只对等值线成立、对颜色面不成立** —— 必须在文档与代码注释里写明这个例外，否则以后一定有人踩。
- 建议：**先 (b)**（守住已有口径），把 (a) 记为后续可选项；无论选哪个，**都要把例外写进 `EXTENSION-POINTS.md`**。

### 决定二：连续场按**整图**采样还是**按视口分块**？

实现选的是"缓存键**不随视口变**" ⇒ 整图采样一次（受 `MAX_FIELD_DIMENSION = 256` 限制），平移不重算。
好处：平移流畅、图元稳定；代价：**地图越大精度越低**（256 个采样点铺满全图，等值线会变粗、抖动）。

- 若接受：请在手册里写明"连续场在大地图上精度有限"，并在 §C 的信息卡/设置里给出可调采样上限的可能（后置）。
- 若要更准：改成按视口分块缓存 —— 代价是拼接缝、缓存管理复杂度、平移时重算。

> 这两条会同时影响 §B（默认值必须进同一份采样）与导出，**请在开 §B 之前定**。

## 5. 逻辑问题清单（按严重度，含建议修法）

### HIGH

**HIGH-1 §C.1 的措辞会让实现去改覆盖层的 `pointer-events`** —— 这会直接违反仓库头号硬约束
（覆盖层永久 `none`；手势只在 `view.containerEl` 捕获阶段处理，且靠 `getUiExclusions` 排除 UI）。
- **建议改写**："覆盖层保持 `pointer-events: none` 不动。工具是否激活只决定**要不要消费**这个事件；
  接管与排除都走既有的捕获路径与 `getUiExclusions()`。"

**HIGH-2 §F.1「显示」三组里，区域 / 路径 / 标记 / 名称 同时出现在「地形」组与「地标与地物」组** ——
同一个布尔开关渲染两遍就是两个真相源（§5.12）。
- **建议**：按一个维度切，例如「底图」= 地形 / 网格 / 数据层；「地物」= 区域 / 路径 / 标记 / 名称。

**HIGH-3 §C.4 与 §F.2 自相矛盾**：C.4 说信息卡**取代侧栏的详情显示**，F.2 仍列「当前状态（只读：当前工具与
已确认的值 · 选中格数）」——那就是只读详情。
- **建议**：要么删掉侧栏那一行，要么把它的定位收窄为"**工具与已确认值**"（与对象详情无关）。

### MEDIUM

**M-1 §C.2 的「当前选择内」当"规则"，与它自己声明的分工冲突**（"规则只做逐格谓词"）。
- **建议**：改成**动作**（在当前选择内再筛 = intersect），或把 selection 作为纯入参传进 `match`。

**M-2 §B.4 与 §E 冲突**：B 承诺"改默认值立刻全图生效（因为没写进格）"；§E 的 `＋/－` 对无值格
"从默认值起算"并**写进格** ⇒ 这些格从此**不再跟随默认值**。
- **建议**：明确写"`＋/－` 会把兜底值**固化**成真数据"，或在笔刷区显式提示；否则就会出现
  "我改了默认值，可刷过的地方没变"。

**M-3 §E 的不对称**：`＋/－` 刷无值格、`×/÷` 跳过无值格 ⇒ 必然收到"为什么有的格没变"。
- **建议**：统一口径，或在笔刷区把这条规则写成人话。

**M-4 兜底格让"颜色 = 有数据"的直觉破裂**：B.3 要兜底格照画，C.4 的统计又"只统计有值格"。
- **建议**：给兜底格视觉区分（略低不透明度 / 斜纹），或卡片上直接写"其中 N 格用的是默认值"。

**M-5 §D 的"最小占位集"建议改成**空集**：占位 ID 会被笔刷、筛选器、图例当真，看起来像官方分类，
而分类明确待定。
- **建议**：内置集为空 + 明确入口（"去『地图定义』新建"），并在设置页写明"分类表可整表替换"。

**M-6 选择的生命周期未定义**：撤销/重做导致被选格消失、切换画布、重新加载地图时选择怎么办？
- **建议**：选择**不进撤销栈**；按 key 保留，卡片显示"其中 N 格已不存在"。

### LOW

- **L-1** `Esc` 的优先级未定义（清空选择 vs 退出工具）→ 明确顺序（例如第一次清选择、第二次退工具）。
- **L-2** §A 的"每层最多 3 个标注"缺少并列时的确定性规则（建议：最长 → 层级小 → 起点字典序），
  否则逐帧抖动，还会让缓存失效。
- **L-3** §F.1 第三组给生物群系列了"越界色 / 展示单位" —— 分类字段没有这些概念。
  这些控件应从**字段规格**派生（像现有 `overlayUnitOf` 那样），不要写死清单。
- **L-4** §E"换层/换模式就清空数值"的代价偏高：可保留数字但标成"未确认"（灰掉/待回车），
  既满足"不静默沿用"，又不用每次重打。
