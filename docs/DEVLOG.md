## 一、这个周期（1.0.0 → 未发布）做了什么

### 1. 自定义定义体系（用户可扩展的四类定义）

| 能力 | 说明 |
|---|---|
| **自定义地形**（更早） | 稳定 `custom:` ID + 显示名 + 颜色 + 字形/图片（单格一张 / 整片一张） |
| **④ 自定义标记图标** | 字形 / 库内图片两种**显式模式**；图片失败回退字形且只尝试/告警一次 |
| **⑤① 路径类型可扩展** | 内置 4 种 + 自定义（上限 32），每型带颜色/线宽/虚线/端点/连接；工具条收进**一个下拉** |
| **⑤② 区域类型统一** | 内置 6 型（王国/帝国/…）+ 自定义（上限 32），每型带填充/不透明度/边框色/边框宽/边框虚线 |
| **③ 定义文件导入导出** | 四类定义打包成 JSON（`version: 2`）；**段缺失 ≠ 段为空**（导入绝不删东西）；同 ID 保留现有；导出不覆盖同名文件；幂等 |
| **改 ID 并迁移引用** | 设置页每行「改 ID…」→ 先给**影响面**（几张地图、共几处）→ 执行时**先改地图文件、再改设置**；幂等、可撤销 |

### 2. 编辑与检查器（A1 / A2 / A3）

| 轮次 | 交付 |
|---|---|
| **A1 选中 + 侧栏检查器** | 点选对象（标记/名称/路径/区域/地块）+ 高亮 + 侧栏显示信息，**可改名称与链接笔记**（修的正是"根本没法重新链接笔记"这个缺陷）、可删除；未选中时给一行引导 |
| **A2 侧栏就地编辑** | 类型（图标/地形/路径类型/区域类型）、位置（x/y、"移到视口中心"）、外观（覆盖色/颜色/线宽/虚线/不透明度/边框）；三组**默认收起** |
| **A3 设置页瘦身 + 引导** | 设置页只留"引导 + 全局开关 + 只影响新对象的参数"；四类定义的增删改搬进「地图定义…」弹窗；**删除定义先说影响面**（没引用就直接删、有引用先弹框并写明"对象不会被删"）；两份「快速上手」 |
| **表驱动** | 命中顺序 / 显示名 / 能力 / 面板动作 / 高亮全部来自 `SELECTION_KINDS` 一张表 —— **加一个新对象种类 = 表里加一行 + 高亮加一行** |

### 3. 数据层（温度 / 深度 / 连续场 / 等值线）

| 能力 | 说明 |
|---|---|
| 地块数据字段 | `temp`（℃）与 `depth`（深度/海拔，m）；**留空 ≠ 0**（`0` 是合法值）；越界直接拒绝 |
| 覆盖层渲染 | 按色带逐格上色 + 越界纯色 + 可选"每格写数值"；**图层表**里温度/深度各一行（八层显示） |
| 海拔标定 | 深度的「相对值」需要地图级标定（弹窗设置）；`elevation` 与文档同级 |
| **连续场模式** | 由格心值插值成连续场 + marching squares 等值线；图元 IR 是**画布与导出共用的同一份几何** |
| **工程图式等值线标注** | 数值沿等值线排布（沿弧长挖空 + 局部切线角旋转） |
| 导出叠加层 | SVG / PNG / Base 缩略图带上数据层；标记按字形绘制、区域按自己的边框与不透明度 |

## 三、这个周期确立的关键决定（改主意前先读这里）

1. **未知值一律保留**：不认识的 ID / 字段 / 段落 / 格上键，一律原样保留 + 告警，回退视觉归绘制层。
2. **一个设置只有一个来源**：旧设置字段迁移后只当镜像（`pathColors` / `regionColors` / `layerVisibility` 的 legacy）。
3. **样式只影响新对象**：已画对象的参数存在地图文件里；改设置不动它们。
4. **显式模式，不做隐式推断**：字形/图片、单格/整片、逐格/连续场都是显式字段。
5. **表驱动**：选中种类、图层、字段规格、筛选规则各有一张登记表，"加一种"= 加一行。
6. **画布与导出共用几何**：连续场的图元 IR 只有一份（`fieldPlan` → `overlayPlan` → 画布 / SVG）。
7. **可撤销**：任何写文档的编辑都走既有 history 路径，一次操作 = 一条历史。
8. **覆盖层永久 `pointer-events: none`**；手势只在容器捕获阶段处理，UI 排除按元素引用。
