## 4. 排版：一大坨怎么拆

**面板（`MapPanel`）**：按"一眼能扫完"分块，每块**首行是一行摘要**，细节默认收起：

```
当前状态        编辑：地形笔刷 · 森林          ← 一行，最重要
工具            地形 / 路径 / 区域 / 标记 / 名称 + 笔刷大小   ← 常用
显示            底图 · 地物 · 数值图层          ← 三个折叠组
选择            方式 · 筛选 · 整批编辑          ← 折叠
地图定义        管理地图定义…                  ← 一个按钮
```

**规则**：① 一个块内**一行一个控件**，不要一行塞三个；② 说明文字统一**放在控件的下方或工具提示**，
不要插在控件之间；③ 数字输入**并排 + 单位后缀**（`10` `℃`），不要写进标签；④ 组与组之间留一行空白；
⑤ 次要组**默认收起**（已有的 `<details>` 用法照旧）；⑥ 一行内标签左对齐、控件右对齐（Obsidian `Setting` 已是）。

**设置页**：同上，且**只留"新对象默认值"**（§A3 已做），把仍显臃肿的说明按 §2 规则砍。

**运算符显示名**（值仍是 token，只改显示）：`=`→等于 · `≠`→不等于 · `in`→属于其中之一 ·
`between`→介于…之间 · `exists`→有 / 没有这个数据 · `>` `≥` `<` `≤` 保持符号。

**其它词**：「子句」→**条件**；「子句之间」→**这些条件的关系**；「+ 添加子句」→**+ 再加一个条件**；
「取反」→**反过来（不满足的行）**；动作「替换 / 并入 / 移出」→ 后面跟**前后格数**：
「替换（→37 格）」「并入（12 → 49 格）」「移出（12 → 4 格）」。

每条条件左侧带一句人话 ✅（人话那行本来就有，本轮没动）；`≠` / 范围 / 取反 / OR 收进默认收起的「更多」 —— **未做**。
