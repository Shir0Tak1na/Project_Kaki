## 4. 纪律（每一步都要守；第 7 条是本轮新增）

1. **覆盖层永久 `pointer-events: none`**；手势在 `view.containerEl` 捕获阶段处理，UI 排除走 `getUiExclusions()`。
   "工具激活"只决定**要不要消费事件**，不是打开覆盖层的指针事件。
2. **未知值一律保留 + 告警**：ID / 字段 / 顶层段落 / 格上未知键，四层都要保真（§5.11）。
3. **一个设置只有一个来源**；旧字段迁移后只当镜像。
4. **四道门**：构建 → `tsc` → 单测 → 冒烟；**新断言必须破坏一次确认变红**（"没红"也是结果，要如实报）。
5. **一次操作 = 一条历史**；写用户数据的改动都要可撤销。
6. **派生数据不入地图文件**（栅格 / 图集 / 缩略图 / 缓存一律不进 `.map.md`）。
7. **留好接口，以便后续开发（本轮新增）**。加任何能力时，先问一句：**"下一个同类东西来的时候，我要改几处？"**
   - 能写成**登记表**的就写成登记表（选中种类 / 图层 / 字段规格 / 筛选规则 / 地形标签 / 生物群系分类）；
   - 能做成**纯函数 IR** 的就做成 IR（画布与导出共用一份几何）；
   - 需要"以后能换一整张配置"的，就别把数据写死在代码里（分类表、色带预设、单位表）；
   - 命名空间与**前缀**留给"用户自定义"（`custom:`），内置保持裸 ID；
   - 结构性变化先落**迁移链**，不要到处撒 `if (version === …)`；
   - **判断标准**：加一个同类东西，理想情况是**加一行**；超过三处就要在 `EXTENSION-POINTS.md` 里记下
     "为什么这次做不到"，并把接缝留出来。
8. **不要**碰真实库；**不要**在没有用户明确要求时 `git commit` / `push` / `tag`（交接/收尾除外）。
