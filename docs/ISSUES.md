## ISSUE-001 · 等值线数字：黑色 / 很大 / 不随线旋转 **＋ 沿线按距离重复**

- **状态**：🟠 诊断中（2026-09-28 用户实测 + 追加要求）
- **报告时基线**：构建 79 模块 / 1214.6 KiB · `tsc` 0 · 单测 589 · 冒烟 1300 断言（场景到 46）

### 1. 现象与期望

**现象（用户原话）**：「等高线数字没弄好，还是黑色的，很大不跟着线走。」
**用户已答**：把设置里「在每个格上写出数值」**关掉**之后，数字**还在**（⇒ 不是格心读数）。
**用户追加要求**：「还要考虑每隔多少距离重复一次数字。」—— 见 **§1.1**。

**期望（设计依据 `DATA-LAYER-PLAN-v5.md` §A）**：

- **颜色**：用**对比色**且带描边，压在彩色场上也要看得见；
- **方向**：沿等值线按**局部切线角**旋转，收进 ±90°（不许倒着看）；
- **大小**：不能比格心读数更大（缩放时不该变成巨字）；
- **断线**：数字处的等值线**真的断开**；
- **重复**：沿每条等值线**每隔一段距离**就重复标一次（不是"每层最多 3 个"）。

### 1.1 追加要求：沿线按距离重复（已写进施工文件 §A.5）

**现行实现**（`fieldPlan.ts:745-790`）：每层只取**最长的 3 条**折线（`.filter(length ≥ 文字宽度×4).sort().slice(0, 3)`），
每条只在**中点**调一次 `cutPolyline(points, gap)` → 切两截 + 1 个数字。

**要求的口径**（可直接落地）：

| 项 | 规则 |
|---|---|
| 取点 | 沿每条线的**弧长**行走，每隔 `spacing` 放一个数字 |
| 间隔 | `spacing = max(重复间隔, 文字宽度 × 6)`；前者是**世界距离**（不随缩放变），后者防挤 |
| 可调项 | **重复间隔**默认 `6 × 格半径`（`grid.size × 6`），设置项单位 = 格，改小立刻变密 |
| 留边 | 两端各留 `文字宽度 × 2`；短于 `文字宽度 × 4` 的线**整条不标** |
| 上限 | 每层 3 → **12**；**全局**（所有层合计）**200**；超限时**沿线均匀抽样**，不许"只留最长几条" |
| 多切点 | 一条线上 N 个数字：**先按弧长算全部切点 → 一次性切成 N+1 段**（`cutPolyline` 只切一次，需要多切点版本） |
| 旋转 | 每个数字取**该处**切线角（经 `keepUpright`） |
| 确定性 | 同一输入产出同一批切点（排序：弧长 → 层级 → 起点坐标），否则逐帧抖动、缓存失效 |

### 2. 我先做的代码核查（结论：三段链路都已实现，问题在**口径**与**取点算法**）

| 环节 | 代码事实 |
|---|---|
| 颜色 | 线色 = **该层级的色带颜色**（`fieldPlan.ts:747,763`）；标签色 = `textColorOf(线色)`（`:780`）；`halo: true` |
| 描边 | 画布 `rgba(255,255,255,0.9)`（`overlayDraw.ts:200-203`）；SVG `stroke="#ffffff"`（`src/base/mapPreview.ts:426`） |
| 旋转 | 切线角在 `cutPolyline` 按"中点所在段的方向"算（`fieldPlan.ts:696`），经 `keepUpright` 收进 ±90°（`:614-618`）；画布 `translate→rotate→(halo)→fillText→restore`（`overlayDraw.ts:188-208`）；SVG `transform="rotate(deg x y)"`（`mapPreview.ts:422`） |
| 字号 | `labelSize = max(8, grid.size × deviceScale × 0.5)`（`overlayDraw.ts:171-172`，`OVERLAY_LABEL_SCALE = 0.5`）；同一式子作为"挖缝宽度"进几何 |
| 取点 | 见 §1.1（每层 3 条、中点各一次） |

**能解释"黑色 / 很大 / 不随线走"的只有两个对象**：

#### 对象 A：越界格标签（**会绕过你刚关掉的开关**）

`fieldPlan.ts:804`：`showValues === true || (labelOutOfRange === true && style.outOfRange !== null)`
—— 「越界格**总是**写数值」是故意的（设置页文案也这么写）。这类标签**三条全中**：
`color: style.textColor`（浅色锚点 → 黑）、**没有 halo**、**水平**、字号同 0.5×格半径。

#### 对象 B：真的是等值线标签 → 问题是**设计口径**，不是实现漏做

1. **黑色**：线色取自色带在该层级的颜色，浅色段 ⇒ `textColorOf` 判成**黑**；而 halo 是**白色**
   ⇒「黑字 + 白边」压在浅色场上**等于看不见**。**要改的是 §A.4 的口径**：
   对比色应与**字底下的场**对比，且 **halo 必须与字色相反**（白字配深边 / 黑字配浅边）。
2. **很大**：字号 = **半个格半径（世界单位）**，缩放时跟着放大 ⇒ 等值线标签应有**自己的比例**（更小）
   或**屏幕固定字号**。
3. **不随线走**：两端都实现了旋转 ⇒ 若真不转，先打印图元里的 `rotation`（水平段算 0 属正常）。

### 3. 请用户再答一句（任一条即可定对象）

1. 数字是**零星几个**（只在最热/最冷的格），还是**沿着等值线成串**出现？
2. 数字**旁边有断开的线**吗？（等值线标签会把线挖断；格心读数附近没有线）
3. **把整个「温度」图层关掉**，数字还在吗？（还在 ⇒ 是另一个数据层，例如深度的越界格标签）

### 4. 修法

**若为对象 A（越界格标签）** —— 不是缺陷，是**没讲清的分工**：

1. 设置页那一项的描述改成「在所有**格心**写出数值（等值线上的数字是另一回事；越界格始终写）」；
2. 给越界格标签一个**单独的、更小的比例**；
3. 允许用户**关掉**越界格标签（现在无开关）。

**若为对象 B（等值线标签）**：

1. **对比色口径改掉**（同步改 `DATA-LAYER-PLAN-v5.md` §A.4）：按**字底下的场色**判黑白，
   **halo 与字色相反**；
2. **字号独立**：新增 `CONTOUR_LABEL_SCALE`（建议 0.35）或改屏幕固定字号；
3. **沿线重复**（§1.1）：把"取最长 3 条各切一次"换成**多切点**算法
   （`cutPolyline` → `cutPolylineAt(points, positions[])`），并按 §1.1 加设置项与上限；
4. 若 `rotation` 恒为 0：查 `cutPolyline` 的取段与 `keepUpright`（见对象 B 第 3 条）。

### 5. 修完必须补的断言（要能变红）

1. **对比色**：文字图元的 `color` 与 halo **必须相反**；对浅色线色**不得**生成"黑字 + 白边"；
2. **旋转**：给定已知斜率的等值线，图元 `rotation` = 该处切线角（±90° 内）；
3. **画布**：绘制期间 `ctx` 变换**包含旋转**、`fillStyle === primitive.color`、halo 时**先 strokeText 后 fillText**；
4. **字号**：等值线标签字号**不随缩放无限放大**（若采用屏幕固定字号，断言"缩放 2× 后字号不变"）；
5. **重复间隔**（§1.1）：长度 L 的直线 → 数字个数 = `floor((L - 2×边)/spacing) + 1`；
   **spacing 减半 ⇒ 数量约翻倍**（单调性）；
6. **多切点**：一条线上 N 个数字 ⇒ 产出 **N 个文字 + (N+1) 段折线**；
7. **确定性**：同一输入连续算两次，切点坐标数组**逐项相等**（防抖动/缓存失效）；
8. **导出一致**：SVG 里同一文字的 `fill` / `transform` / 描边与画布同源（几何只有一份）。

### 6. 验收（可判伪，真实库）

1. 只开等值线（关掉逐格数值）→ 数字压在**深色场**与**浅色场**上都看得清（不再"一坨黑"）；
2. 斜的等值线上数字**跟着斜**，水平线上水平，**没有数字倒着**；
3. 字号**明显小于格宽**，缩放到 200% 时不变成巨字；
4. 数字处等值线**真的断开**（放大看没有线穿过数字）；
5. **一条很长的等值线上，数字每隔大致相等的距离重复出现**（不是只有最长的三条各一个）；
6. 把「重复间隔」调小 → 数字当场变密；调大 → 变疏；
7. 巨大地图上数字**总量有上限**（不爆炸）；
8. 导出 SVG/PNG 与画布**一致**（颜色、倾斜、断线、字号、重复密度）。
