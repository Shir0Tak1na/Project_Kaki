# Project Kaki 用户手册

Project Kaki（译名 Project 垣）是一个 Obsidian 六边形客制化地图创作插件。
它把地图绘制、世界观笔记和 Base 导航放在同一套工作流里。

> 插件 ID 是 `project-kaki`，所以在 Obsidian 里显示为 **Project Kaki**。
> 地图文档里的类型标记 `fictional-cartographer-map`、Base 视图 ID `fictional-map`
> 是写在你自己文件里的持久化标识，升级时**不会**被改动，已有地图和 Base 都照常可用。

## 1. 插件能做什么

当前已经实现：

- 在 Obsidian Canvas 中绘制六边形地形；
- 使用平原、森林、丘陵、山脉、水域、沼泽、沙漠、冻原、火山等内置地形，也可以在设置里加自己的地形（颜色 + 字形，或一张库内图片）；
- 添加地标、文字标注和笔记链接；
- 给地标定义自己的图标（借用内置字形，或用一张库内图片）；
- 绘制河流、道路、贸易路线和边界；
- 绘制国家或领地范围；
- 对地图编辑、地标、路径和区域操作进行撤销/重做；
- 把当前地图导出为 SVG 与 PNG（两者同源；PNG 失败时会给出原因而不是留下空文件），也可以只导出当前视口或某个区域；
- 网格、地形、区域、路径、标记、名称六层可以分别显示或隐藏（只影响显示，不改数据）；
- 在右侧边栏「地图面板」或命令面板里停用当前 Canvas 的地图层；
- 在 Base 中同时查看地图条目和带坐标的笔记；
- 在 Base 缩略图中点击标记、路径、区域、文字或笔记点，跳转到对应文件。

规划中但尚未实现：

- 自定义地形的图块与变体（当前支持"颜色 + 借用内置字形 + 一张库内图片"）；
- 把图例画进导出文件；
- 多图层导出（分层出图 —— 六层开关只影响画布显示，导出仍是一张合成图）；
- 移动端与触控笔交互；
- 更完整的 Base 筛选、分组和导航能力。

## 1.1 地图面板：不用每次翻命令面板

左侧边栏有一个**地图图标**（Project Kaki 的侧边栏按钮），点一下就会在右侧边栏打开**「地图面板」**：

- 面板里按用途分组列出常用动作：**地图层**、**编辑**（绘制模式 / 撤销 / 重做）、
  **地图文件与导出**（创建地图 / 查看状态 / 创建 Base / 导出 SVG）；
- 每个按钮是**一行**（图标 + 名称），状态说明（例如「可撤销 3 步」「已启用：Maps/World.map.md」）
  放在**悬停提示**里 —— 侧边栏很窄，之前每个按钮带一行描述会挤成三四行；
- **当前用不上的按钮是灰的**（例如没启用地图层时"导出 SVG"不可点），点不动比点了报错好；
- 点按钮就等于执行对应命令，执行完面板会自动刷新。

打开面板的三种方式：点左侧边栏的地图图标 · 命令面板运行 **打开地图面板** ·
设置页里的「打开面板」按钮。（面板也可以拖到别的侧边栏位置，Obsidian 会记住。）

### 开发者模式

设置 → Project Kaki 里有 **开发者模式** 开关（默认关闭）：

- **关闭时**：两个探针命令（诊断当前 Canvas / 监视视口变化）会从**命令面板里隐藏** ——
  不是灰掉，而是不出现，避免手快误触；面板里也不会显示「开发工具」一组。
- **打开时**：它们会重新出现（命令面板与地图面板都会多出「开发工具」一组）。

## 2. 安装与测试库
开发版本默认部署到仓库旁边的隔离测试库：

```powershell
cd E:\ObsidianPulgins\fictional-cartographer
node scripts/build.mjs
node scripts/deploy.mjs
```

然后在 Obsidian 中打开：

```text
E:\ObsidianPulgins\test-vault
```

启用社区插件和 `Project Kaki`。测试期间不要把插件部署到正式库。

> 如果你之前装过旧 ID（`fictional-cartographer`）的开发版：`node scripts/deploy.mjs`
> 会把旧目录里的设置（字号倍率、网格、开发者模式）搬到新目录，然后删掉旧目录，
> 并在 `community-plugins.json` 里把启用项换成新 ID。地图文件与 Base 文件不受影响。

## 3. 创建第一张地图

1. 在测试库中打开一个 `.canvas` 文件。
2. 打开命令面板。
3. 运行 **创建地图并绑定到当前 Canvas**。
4. 输入地图名称，例如 `World`。
5. 插件会创建 `Maps/World.map.md`，并将它绑定到当前 Canvas。
6. 运行 **启用/停用当前 Canvas 的地图层**，打开地图显示。

地图数据保存在 `.map.md`，不会修改原始 `.canvas` 文件。

## 4. 在 Canvas 中绘制地形

地图层启用后，工具条会出现在 Canvas 上方。工具条右侧会避开 Obsidian 原生的缩放和卡片控件；在窄窗口中工具条会收缩为可滚动区域。

停用地图层的入口是右侧边栏「地图面板」里的动作，或命令 **启用/停用当前 Canvas 的地图层** ——
画布工具条上原来那个「地图层」按钮已经移除（它会随地图层一起消失，关掉之后就点不到了，见 §10）。

### 4.1 进入绘制模式

- 按 `D`；或
- 运行 **切换绘制/选择模式**；或
- 点击地图工具条上的模式按钮。

绘制模式下，鼠标左键用于绘制。中键平移、右键操作和滚轮缩放仍由 Canvas 处理。

### 4.2 选择地形

按数字键选择内置地形：

| 按键 | 地形 |
|---|---|
| `1` | 平原 |
| `2` | 森林 |
| `3` | 丘陵 |
| `4` | 山脉 |
| `5` | 水域 |
| `6` | 沼泽 |
| `7` | 沙漠 |
| `8` | 冻原 |
| `9` | 火山 |

也可以直接点击工具条中的地形按钮。

### 4.3 调整笔刷

- `[`：减小笔刷；
- `]`：增大笔刷；
- 一次拖动是一条历史记录；
- 松开鼠标后会自动保存地图。

### 4.4 撤销和重做

- `Ctrl/Cmd+Z`：撤销；
- `Ctrl/Cmd+Shift+Z`：重做；
- 也可以点击工具条上的撤销/重做按钮。

## 5. 添加地标和文字

### 5.1 地标

1. 按 `M`，或点击工具条的地标工具。
2. 在地图上点击位置。
3. 填写名称。
4. 选择内置图标。
5. 可选填一个笔记路径。
6. 确认后，地标会吸附到最近的六边形格心。

选择模式下：

- 点击地标：打开它关联的笔记；
- 拖动地标：移动位置并在松开时吸附到格心；
- 右键地标：删除；
- 删除和移动都可以撤销。

### 5.2 文字标注

1. 按 `T`。
2. 点击地图位置。
3. 输入文字。
4. 确认后生成文字标注。

文字标注可以在选择模式下移动、删除和撤销。

### 5.3 自定义标记图标

内置的 9 种图标（城市 / 村镇 / 要塞 / 遗迹 / 港口 / 神殿 / 山峰 / 洞穴 / 塔）不够用时，可以自己加图标。

**在哪里定义**：设置 → 社区插件 → Project Kaki → 找到 **「自定义标记」** 一节。

**怎么新增一条**：在 **「新增自定义标记」** 那一行填 **ID**（例如 `lighthouse`）与
**显示名**（例如 `灯塔`；留空就用 ID），然后点 **「新增」**。

- ID 规则：小写字母开头、2–32 位，可用数字、下划线、连字符（大写会被统一成小写）；
  `custom:` 前缀由插件自动补上 —— 所以地图文件里看到的是 `custom:lighthouse`；
- **边填边校验**：不合法时这一节**底部那一行会就地写出原因**
  （例如"ID 必须以小写字母开头（例如 lighthouse）"），点「新增」也不会写进设置；
- 最多 60 条（到上限时「新增自定义标记」的说明文字会直接写明）。

**两种模式**：每条定义上面有一组**两选一**按钮，决定这一条用哪套视觉（新建时默认「字形」）。

| 模式 | 用什么画 | 需要填 |
|---|---|---|
| **字形** | 借用某个内置图标的形状（下拉里选，另有「通用（圆点）」= 一个圆点）。不依赖任何外部资源，最不容易失败 | 显示名、字形 |
| **图片** | 你库里的一张图片 | 显示名、图片 |

每条还有 **「名称」**（就是显示名，随时可改）与 **「删除」** 按钮；说明文字里会一直写着
`写入地图文件的 ID：custom:xxx（不可修改 —— 改它等于换一种标记）`。

**图片怎么选**（图片模式）：「图片」那一栏可以填库内相对路径（例如 `Assets/lighthouse.png`），
也可以点右边的 **「从库中选择…」** 从库里挑。选择器里**只列图片**
（`png / jpg / jpeg / webp / svg / gif`）；库里一张图片都没有时会明确提示，而不是弹一个空列表。

- **「图片」那一栏在两种模式下都显示**：在「字形」模式下点「从库中选择…」，
  会**自动切到「图片」模式**再让你挑；直接填一个合法路径也一样会自动切过去 ——
  否则你会以为"填了没反应"；
- 路径不合法（例如写成了网址、扩展名不在上面的清单里）时会**就地提示，并且不会写进设置**。

**你会看到什么**：图片模式下，「图片」那一栏的说明文字下面会**直接把这张图画出来**做预览
（按原比例缩放，**不拉伸**），并写明 `当前图片：<路径>`。
如果这张图现在取不到（文件被移走或删掉了），那里会直接写明
"当前取不到这张图的资源地址：文件可能已被移动或删除，画布上会退回字形" ——
而**不会显示一个破图**。

**切换模式不会丢另一边的配置**：图片路径与字形都保留着，切回来还在，可以放心来回试。
只有在设置里**删除这一条**才会真的丢。

**在哪里用**：

- **画布工具条**：按 `D` 进入绘制模式，切到标记工具（快捷键 `M`），图标组里就是
  **内置 9 种在前、你的自定义标记在后**。每个自定义标记的按钮上带**显示名**
  （字形可能只是通用圆点，光看图分不出哪个是哪个），悬停提示里带完整 ID；
  **图片模式的标记，按钮上直接显示你选的那张图**。改完设置不用重开画布，下一次刷新按钮就跟上。
- **放置对话框**：按 `M` 在地图上点一下，弹出「放置标记」。「图标」下拉里同样列出内置 9 种与你的自定义标记
  （下拉里写的是显示名，存进文件的是 ID）。如果你当前选中的图标刚好被删掉了，
  下拉里会多一项「未知（custom:xxx）」，而不会悄悄跳回第一个图标。
- **笔记**：Base 视图里的行也可以指定图标 —— 在笔记 frontmatter 里写
  `map-type: custom:lighthouse`（与地图文件里写同样的值是一个意思），见 §7。

**图片打不开时会怎样**：标记**不会消失**。那一张图加载不出来时（文件被删、路径失效、
或者当前平台拿不到这张图的资源地址），画布上这一条会**回退成它的「字形」**
（没配字形就是「通用」圆点），并在开发者控制台留下一条可读原因
（`标记图片加载失败，已回退为图标字形：<路径>`）。
同一张坏图在**同一次启用地图层期间**只尝试一次、只告警一次，不会每帧撞一次 404、也不会刷屏
（停用地图层再启用会重新试一次）。

**认不出的图标会被保留，不会被改掉**：如果你手工编辑地图文件、或从别人那里拿到一张地图，
里面的图标名在这台机器上没有定义，Project Kaki 会：

- 照常把那个标记画出来（用回退图钉），而不是让它从地图上消失；
- **把文件里的值原样保留** —— 这一点很重要：以前的版本会把它改写成 `town`，
  你保存一次就**永久**改掉了自己的数据，而且没有任何提示；
- 在 **查看当前 Canvas 绑定的地图** 的状态报告里把它算进「告警 N 条」，
  并在开发者控制台（`Ctrl/Cmd+Shift+I`）里写清是**哪个图标被保留了**，
  例如：`未知图标 "lighthouse"，已保留（按回退样式绘制；内置图标：city/town/…）`。
  （内置 9 种与 `custom:` 开头的自定义 ID 都不会告警 —— 只有两边都不沾的名字才会。）

**删掉定义不等于删掉标记**：在设置里删掉一条自定义标记，地图上已经放好的标记仍然留在文件里
（ID 一个字符都没变），只是画成回退图钉。想恢复原样，加回一条**同 ID** 的定义即可。

> **导出里没有标记图标。** SVG / PNG 导出与 Base 缩略图里的标记一律画成一个**固定的小圆点** ——
> 自定义字形与图片都不会出现在导出文件里（导出文件要能脱离你的库打开，内联图片属于后续工作）。

## 6. 绘制河流、道路和领域

### 6.1 路径

1. 按 `P`。
2. 选择河流、道路、贸易路线或边界。
3. 逐点点击添加顶点。
4. 双击、按回车或右键结束。
5. 在命名框中输入名称，也可以留空跳过。

河流会使用平滑曲线并支持末端变细；道路、贸易路线和边界使用各自的线型。

### 6.2 三种几何模式：沿格边 / 逐边 / 穿内部

工具条上有一组按钮，**只在「路径」和「区域」工具下出现**：

| 模式 | 效果 | 适合 |
|---|---|---|
| **沿格边** | 落点吸附到网格顶点，顶点之间**自动沿格边走** | 国界、领地边界——先把形状点出来，中间不用管 |
| **逐边** | 每次点击只沿格边**前进一条边**，方向由点击位置决定 | 需要精确到每一条边的描边（点哪个方向就往哪走） |
| **穿内部**（默认） | 线条直接穿过六边形内部，可以斜穿格子；河流仍是平滑曲线 | 河流、道路、随手画的线 |

使用要点：

1. 先选模式，再开始画（换模式会取消正在画的半个形状）。
2. **沿格边**：你点的每个顶点都会被吸附到最近的网格角上，中间自动补上沿边顶点；
   **预览里看到的就是最终形状**（含沿边的走法），不会"松手之后变样"。
3. **逐边**：每次点击**必定**前进一条边 —— 往哪个方向点，就往那条格边走；想拐弯就往侧面点。
   预览只显示"接下来这一条边"。这个模式不会漏点、也不会有"点了没反应"的情况。
   区域结束时（双击/回车），如果还没绕回起点，剩下的闭合回程同样沿格边走。
4. **沿格边 / 逐边都不做平滑**：平滑会把格边抹成曲线，正好毁掉整齐的效果。末端变细与虚线仍然保留。
5. 沿格边时线条会比直线**略长**（六边形的三条边方向相隔 120°，两点之间要"多走再抵消"，
   最坏约 2 倍）—— 这是换取整齐的代价，不是 bug。逐边模式不存在这个问题（每步就是你点的那条边）。
6. 绘制结果里的 `mode` 字段会记住用的是哪种模式（`edge` / `edge-step` / `interior`；
   缺省为 `interior`，因此旧地图不受影响）。

路径也支持可选的 `link` 字段。当前可以直接在地图文档的 JSON 路径对象中填写：

```json
{
  "id": "p1",
  "type": "river",
  "pts": [[0, 0], [100, 100]],
  "width": 8,
  "color": "#4a9fd8",
  "label": "北境商路",
  "link": "Routes/北境商路.md"
}
```

填写后，Base 表格和 Base 缩略图中的路径都会跳转到该笔记；没有 `link` 时，路径会回退到地图文档本身。
路径绘制或路径重命名完成后会弹出“关联路径笔记”输入框，可以直接填写或留空跳过。

### 6.2 区域

1. 按 `R`。
2. 逐点点击至少三个顶点。
3. 双击、按回车或右键结束。
4. 选择区域颜色。
5. 输入国家或领地名称，也可以留空。

选择模式下双击路径或区域可以改名；右键可以删除。

按 `Esc` 可以取消正在绘制的形状。形状完成后再按 `Esc` 会退出绘制模式。

## 7. 把笔记放到地图上

在笔记的 YAML 前置元数据中加入坐标：

```yaml
---
coordinates: [320, -140]
map-type: city
region: 北境王国
---
```

坐标也支持：

```yaml
coordinates: "320, -140"
```

或：

```yaml
coordinates:
  x: 320
  y: -140
```

坐标写错时，Base 会保留这条笔记并显示警告，不会静默丢失。

## 8. 使用 Base 导航

### 8.1 创建 Base

1. 打开命令面板。
2. 运行 **创建地图 Base 文件（表格视图）**。
3. 打开生成的 `.base` 文件。
4. 将视图类型切换为 **地图**。
5. 在视图选项中确认地图文档和坐标属性。

Base 会把以下内容合并到一张表：

- 地图中的地标；
- 地图中的文字标注；
- 地图中的路径；
- 地图中的区域；
- 笔记中的坐标条目。

### 8.2 地图缩略图

地图文档成功加载后，表格上方会出现缩略图。缩略图包含：

- 六边形地形色块；
- 路径；
- 区域；
- 地图地标；
- 笔记坐标点。

缩略图会跟随 Base 容器宽度变化。地图使用统一的 X/Y 缩放比例，因此容器比例不同时可能出现留白，但地图本身不应被拉伸。

点击缩略图中的路径、区域、文字、地图地标或笔记点，会打开对应文件。地形格没有独立文件，因此不提供单格跳转。

| 启用/停用当前 Canvas 的地图层 | 显示或隐藏地图图层 |
| 切换绘制/选择模式 | 切换编辑状态 |
| 撤销 / 重做地图编辑 | 操作地图历史 |
| 创建地图 Base 文件（表格视图） | 创建 Base 起始文件 |
| 查看当前 Canvas 绑定的地图 | 打开**报告面板**：地图统计、名称实际字号与实测标定、图层与图例；面板里可**复制**或**导出为库内文件** |
| 导出地图…（可选范围与格式） | 打开对话框，同时选**范围**（全部内容 / 当前视口 / 某个区域）与**格式**（SVG / PNG） |
| 导出当前地图为 SVG | 快捷方式（= 全部内容 + SVG）：生成 `地图名.svg` 并打开（矢量，可无损缩放） |
| 导出当前地图为 PNG | 快捷方式（= 全部内容 + PNG）：生成 `地图名.png`（1600×1000 位图）；与 SVG 同源，失败时给出可读原因且不留空文件 |
| 诊断当前 Canvas | 输出 Canvas 私有 API 探针报告（同样打开报告面板；开发用） |
| 监视视口变化 | 统计视口事件和有效变化 |

### 9.1 导出时怎么选范围

打开「导出地图…」对话框后，先选**范围**再选**格式**：

- **全部内容**（默认）：和以前一样，把地图上所有东西一起装进一张图；
- **当前视口**：只导你现在**看得见的那一块** —— 先把画布平移/缩放到合适的位置，再导出；
- **某个区域**：从下拉里选一个你画过的区域（例如「北境领」），按它自己的范围导出。

**为什么需要这个**：导出和图例缩略图都是"把全部内容等比缩进画布"，
所以只要有一个**离主体很远的孤立格**，整张图就会被压小（实现时量过的一个例子：同一块
200×200 的区域，按区域导出时占高约 709/1000 px，按全部内容导出只剩约 10/1000 px；
具体比例取决于你地图上离群内容有多远）。
选「当前视口」或「某个区域」就不会再有这个问题。

两点需要知道：

- **按范围导出不会丢内容**：范围外的内容仍然画了，只是落在视野之外被裁掉 ——
  地图文件里一个字节都没变，换回「全部内容」导出，它们就都在；
- **文件名会带上范围**：全部内容不加后缀（老名字不变）、当前视口是 `-视口`、
  按区域是 `-区域名`（名字里的 `/`、`:` 会被换成 `-`；没起过名字的用「未命名区域 N」）。
  重名照旧自动加 `-2`、`-3`。

导出失败时（例如当前环境不支持把 SVG 转成位图），**对话框会留在原地**并给出可读原因，
你可以换个格式再试一次 —— 而且**不会留下一个空文件**，免得你以为导出成功了。

## 10. 已知限制与后续规划

### 当前设置

在 Obsidian 设置 → 社区插件 → Project Kaki 中，目前可以调整：

- 路径与区域名称字号倍率（右侧会显示换算后的实际 CSS 字号，便于直接读数）；
- 是否显示六边形网格；
- 样式：4 种路径的默认颜色、6 个区域预设色、名称字体族（留空 = 跟随主题）；
  「恢复默认」一键还原。**颜色只影响新画的对象** —— 已画好的路径/区域把颜色存在地图文件里，
  改设置不会改动它们；
- 自定义地形：加自己的地形类型。每条先选**模式**：
  **调色**（颜色 + 可借用的内置字形，不依赖外部资源，新建时默认）或
  **图片**（用一张库内图片当图块，颜色作为图片加载失败时的回退色）。
  图片模式还能选**显示方式**：**单格一张**（每个六边形各一张）或
  **整片一张（连通区域）**（连通的同类型格共用一张图，保持比例、只画在连通区域内，超出部分裁掉）。
  ID 是写进地图文件的标识（`custom:` 前缀会自动补上），显示名只是界面文案 ——
  **改显示名、甚至删掉定义，都不会改动你已经画好的格子**；
  **切换模式不会丢另一边的配置**（图片路径与字形都保留，切回来还在）；
  图片支持 `png / jpg / jpeg / webp / svg / gif` 的库内相对路径，路径可以**手打**，
  也可以点右边的「从库中选择…」从库里挑（Obsidian 没给插件系统文件对话框，所以只能从库里选）；
  图片不可用时会回退成颜色 + 字形并在控制台给出原因；图片目前只画在画布上
  （Base 缩略图与 SVG 导出用回退色）；
- 自定义标记：加自己的标记图标（见 §5.3）。每条先选**模式**：
  **字形**（借用某个内置图标的形状，不依赖外部资源，新建时默认）或
  **图片**（用一张库内图片，图片打不开时回退成这条的「字形」）。
  ID 是写进地图文件的标识（`custom:` 前缀会自动补上），显示名只是界面文案 ——
  **改显示名、甚至删掉定义，都不会改动你已经放好的标记**；
  **切换模式不会丢另一边的配置**；图片支持 `png / jpg / jpeg / webp / svg / gif` 的库内相对路径，
  可以手打，也可以点「从库中选择…」从库里挑；图片模式下这一栏会直接给出预览；
  最多 60 条。**标记图标目前只画在画布上**：SVG/PNG 导出与 Base 缩略图里是固定的小圆点；
- 图层开关：地形 / 网格 / 区域 / 路径 / 标记 / 名称 六层可分别显示或隐藏。
  **开关就在右侧边栏「地图面板」的顶部**（设置页里也有同一组，改的是同一份设置）；
  它只影响**显示**，不会改动地图文件里的数据（隐藏路径后再打开，路径还在）；
- 停用地图层的入口是「地图面板」里的动作与命令面板：画布工具条上原来那个「地图层」按钮已移除 ——
  它会随地图层一起消失，关掉之后就点不到了；
- 图例（默认隐藏）：画布右下角列出地图上实际有的地形/路径/区域及其数量，
  内容随地图与图层开关变化，不会列出一份写死的清单；
- 开发者模式（默认关闭，打开后才会出现两个探针命令）。

路径线型、区域颜色、内置地形颜色和标记图标目前通过 Canvas 工具条选择。名称字体族（留空 = 跟随主题）、自定义地形与自定义标记图标都已经可以在设置里改（见上面「当前设置」与 §5.3）；仍未实现的是完整颜色面板与自定义字形（字形只能借用内置 9 种，或者改用一张库内图片）。

### 自定义地形

内置 9 种地形之外，可以加自己的地形类型：设置 → 社区插件 → Project Kaki → 「自定义地形」。
每条填 **ID**（小写字母开头、2–32 位，可用数字、下划线、连字符；`custom:` 前缀由插件自动补上）
与**显示名**（留空就用 ID），最多 40 条。两种模式（见上面「当前设置」）：

- **调色**（新建时默认）：颜色自己挑，字形可以**借用内置 9 种之一的字形**，也可以选「通用」；
- **图片**：用一张库内图片当图块（路径可以手打，也可以点「从库中选择…」），
  还能选**显示方式** —— **单格一张**（每个六边形各一张，默认）或
  **整片一张（连通区域）**（连通的同类型格共用一张图，保持比例、只画在连通区域内）；
  图片取不到时回退成这条地形的颜色 + 字形，并在控制台写明原因。

改完设置不用重开画布：绘制模式下的地形按钮就是「内置 9 种在前、你的自定义地形在后」——
自定义地形**不占用数字键** `1`–`9`，用鼠标点选，悬停提示里有完整 ID。
与自定义标记同一条口径：ID 才是写进地图文件的值（`t: "custom:swamp2"`），
**改显示名、甚至删掉定义，都不会改动你已经画好的格子**（数据原样留在文件里，只是画成回退样式）。

还不能：

- **图块与变体**：每种自定义地形目前只有一套视觉（颜色 + 一个借用来的字形，或者一张图片），
  没有同一地形的多个图块，也没有旋转、镜像这类变体；
- **图片进导出**：图片目前只画在画布上，Base 缩略图与 SVG 导出用回退色
  （导出文件要能脱离你的库打开，内联图片属于后续工作）。

后续的图块与变体会沿用现有的稳定 ID（`custom:` 前缀），避免已有地图因资源改名而失效。

### Base 导航增强

当前 Base 已经支持表格、缩略图和基本点击跳转。后续可以继续增加：

- 地图条目按来源、区域和类型筛选；
- 缩略图与表格行联动高亮；
- 从地图元素反向打开或创建笔记；
- 更清晰的图例和导航状态；
- 大量条目的虚拟滚动。
