# Project Kaki 用户手册

Project Kaki（译名 Project 垣）是一个 Obsidian 六边形客制化地图创作插件。
它把地图绘制、世界观笔记和 Base 导航放在同一套工作流里。

> 插件 ID 是 `project-kaki`，所以在 Obsidian 里显示为 **Project Kaki**。
> 地图文档里的类型标记 `fictional-cartographer-map`、Base 视图 ID `fictional-map`
> 是写在你自己文件里的持久化标识，升级时**不会**被改动，已有地图和 Base 都照常可用。

## 1. 插件能做什么

当前已经实现：

- 在 Obsidian Canvas 中绘制六边形地形；
- 使用平原、森林、丘陵、山脉、水域、沼泽、沙漠、冻原、火山等内置地形，也可以在「地图定义…」里加自己的地形（颜色 + 字形，或一张库内图片）；
- 添加地标、文字标注和笔记链接；
- 给地标定义自己的图标（借用内置字形，或用一张库内图片）；
- 绘制河流、道路、贸易路线和边界；
- 绘制国家或领地范围；
- 对地图编辑、地标、路径和区域操作进行撤销/重做；
- 给格子挂上**温度 / 深度 / 生物群系**，按色带或分类配色画成覆盖层（见 §10 的「生物群系」一节）；
- 一次**选中一整片格子**（矩形框选 / 笔迹框选 / 加减选 / 按规则筛选），右上角看统计，侧栏**整批编辑**（§5.6 / §5.7）；
- 用**数据层笔刷**把温度 / 深度按 `＋ − × ÷` 刷成一片，或把生物群系"设为某个群系"（见 §10 的「用笔刷批量刷数据层」）；
- 把当前地图导出为 SVG 与 PNG（两者同源；PNG 失败时会给出原因而不是留下空文件），也可以只导出当前视口或某个区域；
- 网格、地形、温度、深度、生物群系、区域、路径、标记、名称**九层**可以分别显示或隐藏（只影响显示，不改数据）；
- 在右侧边栏「地图面板」或命令面板里停用当前 Canvas 的地图层；
- 在 Base 中同时查看地图条目和带坐标的笔记；
- 在 Base 缩略图中点击标记、路径、区域、文字或笔记点，跳转到对应文件；
- 定义自己的**路径类型**（内置河流 / 道路 / 贸易路线 / 边界之外自己加，每种可调颜色、线宽、虚线、端点、连接）；
- 定义自己的**区域类型**（内置 6 种之外自己加，每种可调填充色、不透明度、边框色、边框宽、边框虚线）；
- 把四类自定义定义**导出成一份定义文件**、或**从定义文件导入**（备份、换库、分享给别人）；
- 设置页顶部与侧栏面板各有一份**「快速上手」清单**（各自讲各自的入口，可一键隐藏、随时点回来），
  以及「地图定义…」弹窗里集中管理四类定义（新增 / 删除 / 改 ID）。

规划中但尚未实现：

- **自定义生物群系的"新增 / 删除 / 改 ID"界面**（内置 34 条已可用，也能**逐条改颜色**；
  目录与配色通路已在代码里就位，缺的是那几个入口）；
- 自定义地形的图块与变体（当前支持"颜色 + 借用内置字形 + 一张库内图片"）；
- 把图例画进导出文件；
- 多图层导出（分层出图 —— 九层开关只影响画布显示，导出仍是一张合成图）；
- 移动端与触控笔交互；
- 更完整的 Base 筛选、分组和导航能力。

## 1.1 地图面板：不用每次翻命令面板

左侧边栏有一个**地图图标**（Project Kaki 的侧边栏按钮），点一下就会在右侧边栏打开**「地图面板」**：

- 面板最上面是一份**「快速上手」清单**（讲"画的时候手边能干什么"，与设置页顶部那份不同）；
  点「不再显示」可以收起它，收起后留一行「已隐藏 · 重新显示」，随时点回来（设置页那份互不影响）；
- 往下是**「显示」**：**底图**（地形 · 温度 · 深度 · 生物群系 · 网格）与**地物**（区域 · 路径 · 标记 · 名称
  +「显示图例」）两行开关，再下面是一个默认收起的**「数据层参数」**折叠组
  （色带 / 分类配色 / 不透明度 / 显示方式 / 展示单位 —— **与设置页「数据层」是同一份控件**）；
- 再往下是**选中的对象**（或选中 ≥ 2 格时的**整批编辑**），最后才按用途分组列出常用动作：
  **地图层**、**编辑**（绘制模式 / 撤销 / 重做）、
  **文件与导出**（创建地图 / 查看状态 / 创建 Base / 导出地图… / 导出 SVG / 导出 PNG）、
  **地图定义**（**管理地图定义…**，见 §5.3 / §6.4 / §10）；
  **定义文件的导入 / 导出已搬到设置页**（设置 → Project Kaki → 最下面「定义文件（导入 / 导出）」，见 §9.2）；
- 每个按钮是**一行**（图标 + 名称），状态说明（例如「可撤销 3 步」「已启用：Maps/World.map.md」）
  放在**悬停提示**里 —— 侧边栏很窄，之前每个按钮带一行描述会挤成三四行；
- **当前用不上的按钮是灰的**（例如没启用地图层时"导出 SVG"不可点），点不动比点了报错好；
- 点按钮就等于执行对应命令，执行完面板会自动刷新。

打开面板的三种方式：点左侧边栏的地图图标 · 命令面板运行 **打开地图面板** ·
设置页里的「打开面板」按钮。（面板也可以拖到别的侧边栏位置，Obsidian 会记住。）

### 开发者模式

设置 → Project Kaki 里有 **开发者模式** 开关（默认关闭）：

- **关闭时**：两个探针命令（诊断当前 Canvas / 监视视口变化）会从**命令面板里隐藏** ——
  不是灰掉，而是不出现，避免手快误触；面板里也不会显示「开发工具」一组。
- **打开时**：它们会重新出现（命令面板与地图面板都会多出「开发工具」一组）。

## 2. 安装与测试库
开发版本默认部署到仓库旁边的隔离测试库：

```powershell
cd E:\ObsidianPulgins\fictional-cartographer
node scripts/build.mjs
node scripts/deploy.mjs
```

然后在 Obsidian 中打开：

```text
E:\ObsidianPulgins\test-vault
```

启用社区插件和 `Project Kaki`。测试期间不要把插件部署到正式库。

> 如果你之前装过旧 ID（`fictional-cartographer`）的开发版：`node scripts/deploy.mjs`
> 会把旧目录里的设置（字号倍率、网格、开发者模式）搬到新目录，然后删掉旧目录，
> 并在 `community-plugins.json` 里把启用项换成新 ID。地图文件与 Base 文件不受影响。

## 3. 创建第一张地图

1. 在测试库中打开一个 `.canvas` 文件。
2. 打开命令面板。
3. 运行 **创建地图并绑定到当前 Canvas**。
4. 输入地图名称，例如 `World`。
5. 插件会创建 `Maps/World.map.md`，并将它绑定到当前 Canvas。
6. 运行 **启用/停用当前 Canvas 的地图层**，打开地图显示。

地图数据保存在 `.map.md`，不会修改原始 `.canvas` 文件。

## 4. 在 Canvas 中绘制地形

地图层启用后，**画布左上角**会出现一个**状态浮窗**：它告诉你「这个框现在属于谁」（`空闲` / `绘制 · 地形笔刷` / `选择 · 矩形框选 · 12 格`）、当前笔刷的参数（或「为什么画不动」）、下一步能按什么键，以及**进入 / 退出绘制**与**撤销 / 重做**两个按钮。

**工具与所有参数都在右侧边栏的「地图面板」里**（见 §4.2 / §4.3，以及「用笔刷批量刷数据层」一节）：从上往下是「显示」→「笔刷」→「选择方式」→「选中的对象」→「工具」。浮窗在窄窗口中会收缩为可滚动区域。

停用地图层的入口是右侧边栏「地图面板」里的动作，或命令 **启用/停用当前 Canvas 的地图层** ——
画布工具条上原来那个「地图层」按钮已经移除（它会随地图层一起消失，关掉之后就点不到了，见 §10）。

### 4.1 进入绘制模式

- 按 `D`；或
- 运行 **切换绘制/选择模式**；或
- 点击地图工具条上的模式按钮。

绘制模式下，鼠标左键用于绘制。中键平移、右键操作和滚轮缩放仍由 Canvas 处理。

### 4.2 选择地形

按数字键选择内置地形：

| 按键 | 地形 |
|---|---|
| `1` | 平原 |
| `2` | 森林 |
| `3` | 丘陵 |
| `4` | 山脉 |
| `5` | 水域 |
| `6` | 沼泽 |
| `7` | 沙漠 |
| `8` | 冻原 |
| `9` | 火山 |

也可以点右侧边栏「地图面板」→「**笔刷**」→「刷什么」选「地形」，再点下面那一排地形色块。

### 4.3 调整笔刷

- `[`：减小笔刷；
- `]`：增大笔刷；
- 一次拖动是一条历史记录；
- 松开鼠标后会自动保存地图。

### 4.4 撤销和重做

- `Ctrl/Cmd+Z`：撤销；
- `Ctrl/Cmd+Shift+Z`：重做；
- 也可以点击工具条上的撤销/重做按钮。

## 5. 添加地标和文字

### 5.1 地标

1. 按 `M`，或在右侧边栏「地图面板」→「**工具**」里点「标记」。
2. 在地图上点击位置。
3. 填写名称。
4. 选择内置图标。
5. 可选填一个笔记路径。
6. 确认后，地标会吸附到最近的六边形格心。

选择模式下：

- 点击地标：打开它关联的笔记；
- 拖动地标：移动位置并在松开时吸附到格心；
- 右键地标：删除；
- 删除和移动都可以撤销。

### 5.2 文字标注

1. 按 `T`。
2. 点击地图位置。
3. 输入文字。
4. 确认后生成文字标注。

文字标注可以在选择模式下移动、删除和撤销。

### 5.3 自定义标记图标

内置的 9 种图标（城市 / 村镇 / 要塞 / 遗迹 / 港口 / 神殿 / 山峰 / 洞穴 / 塔）不够用时，可以自己加图标。

**在哪里定义**：侧栏面板 →「**地图定义**」→「**管理地图定义…**」，打开弹窗后展开**「标记」**一组
（四组默认收起，点标题展开；详见 §10「地图定义」）。

**怎么新增一条**：在 **「新增自定义标记」** 那一行填 **显示名**（例如 `灯塔`），
然后点 **「新增」** —— **ID 可以留空，插件会自己生成**（见下）。

- **ID 不用自己想了**：留空即可。插件按显示名生成 —— `My Forest` → `custom:my-forest`；
  纯中文名（例如「后花园」）得到 `custom:marker1` 这类"类别 + 序号"的短 ID，序号自动递增。
  **同一个显示名建两次也不会撞车**，会依次拿到 `custom:marker1`、`custom:marker2`；
- **想自己指定 ID 也仍然可以**（高级用法）：规则是小写字母开头、2–32 位，可用数字、下划线、连字符
  （大写会被统一成小写）；`custom:` 前缀由插件自动补上 —— 所以地图文件里看到的是 `custom:lighthouse`；
- **边填边校验**：不合法时这一节**底部那一行会就地写出原因**
  （例如"ID 必须以小写字母开头（例如 lighthouse）"），点「新增」也不会写进设置；
- 最多 60 条（到上限时「新增自定义标记」的说明文字会直接写明）。

**两种模式**：每条定义上面有一组**两选一**按钮，决定这一条用哪套视觉（新建时默认「字形」）。

| 模式 | 用什么画 | 需要填 |
|---|---|---|
| **字形** | 借用某个内置图标的形状（下拉里选，另有「通用（圆点）」= 一个圆点）。不依赖任何外部资源，最不容易失败 | 显示名、字形 |
| **图片** | 你库里的一张图片 | 显示名、图片 |

每条还有 **「改 ID…」** 与 **「删除」** 两个按钮（显示名就是「名称」那一栏，随时可改）；
说明文字里会一直写着当前写进地图文件的 ID（例如 `custom:lighthouse`）。
**改 ID 会把地图里已放好的标记一起迁移**（会先说影响面，见 §5.4）；**删除**不碰地图文件（见 §5.4）。

**图片怎么选**（图片模式）：「图片」那一栏可以填库内相对路径（例如 `Assets/lighthouse.png`），
也可以点右边的 **「从库中选择…」** 从库里挑。选择器里**只列图片**
（`png / jpg / jpeg / webp / svg / gif`）；库里一张图片都没有时会明确提示，而不是弹一个空列表。

- **「图片」那一栏在两种模式下都显示**：在「字形」模式下点「从库中选择…」，
  会**自动切到「图片」模式**再让你挑；直接填一个合法路径也一样会自动切过去 ——
  否则你会以为"填了没反应"；
- 路径不合法（例如写成了网址、扩展名不在上面的清单里）时会**就地提示，并且不会写进设置**。

**你会看到什么**：图片模式下，「图片」那一栏的说明文字下面会**直接把这张图画出来**做预览
（按原比例缩放，**不拉伸**），并写明 `当前图片：<路径>`。
如果这张图现在取不到（文件被移走或删掉了），那里会直接写明
"当前取不到这张图的资源地址：文件可能已被移动或删除，画布上会退回字形" ——
而**不会显示一个破图**。

**切换模式不会丢另一边的配置**：图片路径与字形都保留着，切回来还在，可以放心来回试。
只有在「地图定义…」弹窗里**删除这一条**才会真的丢。

**在哪里用**：

- **右侧边栏「地图面板」→「工具」**：按 `D` 进入绘制模式，切到标记工具（快捷键 `M`），「图标」那一排就是
  **内置 9 种在前、你的自定义标记在后**。每个自定义标记的按钮上带**显示名**
  （字形可能只是通用圆点，光看图分不出哪个是哪个），悬停提示里带完整 ID；
  **图片模式的标记，按钮上直接显示你选的那张图**。改完设置不用重开画布，下一次刷新按钮就跟上。
- **放置对话框**：按 `M` 在地图上点一下，弹出「放置标记」。「图标」下拉里同样列出内置 9 种与你的自定义标记
  （下拉里写的是显示名，存进文件的是 ID）。如果你当前选中的图标刚好被删掉了，
  下拉里会多一项「未知（custom:xxx）」，而不会悄悄跳回第一个图标。
- **笔记**：Base 视图里的行也可以指定图标 —— 在笔记 frontmatter 里写
  `map-type: custom:lighthouse`（与地图文件里写同样的值是一个意思），见 §7。

**图片打不开时会怎样**：标记**不会消失**。那一张图加载不出来时（文件被删、路径失效、
或者当前平台拿不到这张图的资源地址），画布上这一条会**回退成它的「字形」**
（没配字形就是「通用」圆点），并在开发者控制台留下一条可读原因
（`标记图片加载失败，已回退为图标字形：<路径>`）。
同一张坏图在**同一次启用地图层期间**只尝试一次、只告警一次，不会每帧撞一次 404、也不会刷屏
（停用地图层再启用会重新试一次）。

**认不出的图标会被保留，不会被改掉**：如果你手工编辑地图文件、或从别人那里拿到一张地图，
里面的图标名在这台机器上没有定义，Project Kaki 会：

- 照常把那个标记画出来（用回退图钉），而不是让它从地图上消失；
- **把文件里的值原样保留** —— 这一点很重要：以前的版本会把它改写成 `town`，
  你保存一次就**永久**改掉了自己的数据，而且没有任何提示；
- 在 **查看当前 Canvas 绑定的地图** 的状态报告里把它算进「告警 N 条」，
  并在开发者控制台（`Ctrl/Cmd+Shift+I`）里写清是**哪个图标被保留了**，
  例如：`未知图标 "lighthouse"，已保留（按回退样式绘制；内置图标：city/town/…）`。
  （内置 9 种与 `custom:` 开头的自定义 ID 都不会告警 —— 只有两边都不沾的名字才会。）

**删掉定义不等于删掉标记**：删掉一条自定义标记，地图上已经放好的标记仍然留在文件里
（ID 一个字符都没变），只是画成回退图钉。想恢复原样，加回一条**同 ID** 的定义即可。
**已经有地图在用它时，删除会先弹一个确认框**把影响面说清楚（"N 张地图里共 M 处引用"、逐文件明细，
并写明**这些对象不会被删除、只是画成回退样式**）；没有引用就直接删，不打扰（详见 §5.4）。

> **导出侧与画布现在是同一套外观**（2026-09-27 起）：标记按它自己的**图标字形**画，
> 区域带它自己的**不透明度与边框（含虚线）**。两处例外都是"导出文件要能脱离库打开"逼出来的：
> **图片模式的标记**回退成字形、**地形图片**只画底色（不内联库内图片）。
> 注意这条口径只针对**用户库内的图片**：**派生的、有上限的**图**可以**内联
> （连续场的颜色面就是一张内联 PNG，上限 128 KiB，超了这个数就退回矢量多边形）。
> 拿不到字形时回退成小圆点 —— **对象绝不会消失**（未知图标名也一样）。

### 5.4 改 ID 并迁移已画对象

自定义地形 / 标记 / 路径类型 / 区域类型建好之后，ID 也可以改 —— 「地图定义…」弹窗里每一行自定义定义右边都有一个
**「改 ID…」** 按钮。内置类型（河流 / 道路 / 王国…）没有这个按钮：它们的 ID 写死在程序里，改了等于把内置语义改坏。

点开会弹出一个对话框，标题写着改的是哪一条，正文提醒你：**ID 是写在地图文件里的内部标识，改它会把引用一起改掉。**
输入新 ID 之后，对话框下方会**实时**告诉你影响面，例如：

> 将把 2 张地图里共 3 处引用从 `custom:old` 改成 `custom:new`，并把标记定义的 ID 一并改掉：
> · Maps/World.map.md：2 处
> · Maps/Other.map.md：1 处

- **没点「改 ID」之前不会写盘** —— 上面那段只是预览；
- 新 ID 与旧 ID 相同、或与已有定义重名时会被拒绝并给出原因，对话框**不会关**，改一下就能重试；
- 执行时**先改地图文件、再改设置**；已经打开的画布会自动重新读盘，不会停留在「未知（旧 ID）」；
- 完成后弹出**报告面板**，列出改了哪几张地图、各几处（多行内容不塞进小提示，方便你复制留档）。

> **这会改写你已有的地图文件。** 建议先在一张小图上试一次，或者先备份 —— 改名本身是幂等的（重复跑结果一致），
> 但改之前的地图内容不会自动留副本。

**删除定义同样先说影响面**（每行右边的「删除」按钮）：如果**已经有地图在用它**，会先弹一个确认框，
写明"**N 张地图里共 M 处引用** `custom:xxx`"、逐文件列出各几处，并点明两件事 ——
**这些对象不会被删除、仍留在文件里**（只是画成回退样式），以及删除的只是这条定义、随时可以重建。
**取消**则什么都不做；**确认**才真的从设置里移除（同样**不碰任何地图文件**）。
如果**一条引用都没有**，就不弹框、直接删掉（那种情况没有影响面可说，弹框只会白挡一下）。
删除与改 ID 最大的区别：**删除不改写地图文件**，所以它是安全的、不需要备份。

### 5.5 选中对象：侧栏检查器

不用再记快捷键了。**在「选择」模式下点一下地图上的对象**（标记 / 文字名称 / 路径 / 区域 / 地块），它就会被选中并高亮，
右侧边栏出现「**选中的对象**」：种类、名称、ID、坐标或顶点数，下面就是能对它做的事。

- **改名称**：直接改，回车生效，画布上立刻更新；
- **改链接的笔记**：这是**从地图跳回笔记**用的。可以直接输入路径、点「**选择笔记…**」从库里挑，
  或者点「清除链接」；改完写进地图文件，`Ctrl+Z` 能撤销；
- **删除**：删掉这个对象（可撤销）；
- 下面还有**四组默认收起**的（**展开哪一组会记住**：改完一个值不会又全部收起）：
  - **类型**：标记改图标、地块改地形、路径改类型、区域改类型。本机没有的类型会显示「未知（ID）」并保持原值 ——
    所以从别的库拿来的地图，你能看见它用的是什么、也能改成自己的类型。**改类型只改这一个对象**，不会连带改颜色线宽；
  - **位置**：标记（和名称）可以改 x/y 数字，或点「移到视口中心」；路径与区域也能「移到视口中心」（整体平移、不变形）；
    地块显示只读的 `q, r`（地块**不能**搬动）；
  - **外观**：标记与地块可以设「覆盖色」（点「清除」恢复），路径可以改颜色 / 线宽 / 虚线，区域可以改颜色 / 不透明度 / 边框；
    数字填得越界会被**直接拒绝**（不会悄悄改成边界值）；
  - **数据层**（只对**地块**出现）：**温度（℃）** 与 **深度 / 海拔（m）** 两个数值。
    它们是**给覆盖层上色用的数据**，与"外观"是两回事，所以单独一组；
    **留空 = 这一格没有这个数据**，而写 `0` 是**合法值**（0 ℃、海平面都是真实数据，两者不是一回事）。
    **它们没有取值范围**：-200 ℃、99999 m 都能写进去、也会原样存进地图文件 ——
    "超出范围"只体现在**颜色**上：比色带最低端还低的值用色带的「低于下限」颜色（出厂纯蓝）、
    比最高端还高的用「高于上限」颜色（出厂纯红），并在格上**写出它的实际数值**，这样"超出多少"一眼能读。
    深度是**同一个量**：`0 = 海平面`、正数 = 向下（深度）、负数 = 向上（海拔），单位固定是米；
    "换成千米 / 相对值来看"是**显示偏好**（见下面「数据层」一节），**不动文件里的值**。
    两条数据层都接了画布渲染，开关在「图层」组里的「温度」与「深度」（出厂都是关的）。
- **改完了想退回去**：只要这一次选中里改过东西，检查器上就会出现一行
  「**本次选中已改 N 处**」+「**撤销这些改动**」按钮。点它就把**选中之后**的这些改动**逐条撤销**回去
  （点多了还能 `Ctrl/Cmd+Shift+Z` 重做回来）。
  之所以没有"保存 / 取消"：这里的每一次改动**当场就生效、也当场就能撤销**，
  再加一层"待保存"只会让撤销变粗、也不会更安全。
- **什么都没选中**时，检查器会提示你「点一下地图上的对象来选中它」。

> 快捷键**都还在**（`Delete` 删除、`Enter` 改名等），它们现在只是加速器 —— 想不起来也没关系，点选即可。
> 所有改动都进撤销栈：一次提交 = 一步历史，`Ctrl+Z` 逐步回退。

### 5.6 一次选中一整片格子（框选）

**「选择」模式下按住左键拖动**就会框选一片格子。两种方式，在右侧边栏「地图面板」→「**选择方式**」里切换：

- **矩形框选**：拉出一个框，框里的格被选中；
- **笔迹框选**：按住左键划过去，笔迹扫过的格被选中（范围跟「笔刷大小」同一个半径）。

加与减：

- **`Shift` + 拖动** = 把这一片**并进**选择；**`Shift` + 点一下** = 加一格；
- **`Alt` + 拖动 / 点一下** = 把这一格（或这一片）**从选择里拿掉** ——
  注意这是"只取消这几个"，**不是"取反"**（选了 14 格、Alt 掉 1 格 = 剩 13 格）；
- **`Esc`** = 先清空选择（选择本来就空时再按一次才是退出工具）。

选中的格子画**橙色描边圈**。选择**不进撤销栈**：`Ctrl+Z` 不会把选择一起换掉，
撤销 / 重做 / 重载地图之后**选择还在**（按格的位置记住）；如果其中某些格已经不存在了，
信息卡会写明"其中 N 格已不存在"。

> 硬纪律：插件**永不接管右键 / 中键 / 滚轮 / 空格拖动** —— 那些始终是 Canvas 自己的
> 平移与菜单手势。**标记 / 文字上**的左键也留给它们自己（点开笔记、拖动移动）。

**右上角的选择信息卡**（没有选择时整张收起）：

- 选中**一格**：坐标、地形、温度、深度、生物群系 —— **没有的字段写"未填"**，不会猜成 0；
- 选中**多格**：总格数 · 坐标范围（q/r 最小–最大）· 地形种类与各自数量 ·
  **温度的众数** · **深度的平均数** · **生物群系清单** · 有几格没有数据
  （其中几格用的是「每格默认值」会**单独说明** —— 否则"有颜色 = 有数据"这个直觉是错的）。

**侧栏在选中 ≥ 2 格时换成「整批编辑」**：给这批格写温度 / 深度，或**清除该值**。
- **一次提交 = 一条历史**：`Ctrl+Z` 一次把所有格一起回退；
- **输入框不预填共同值**：这批里既有有值的、也有没有值的时，输入框留空并写明
  "这批里有 N 格没有数据" —— 填了才算数；
- **「清除该值」是删掉那个键**，与写一个 `0` 是两件事。

### 5.7 按规则筛选选择

命令面板，或右侧边栏「地图面板」→「选择方式」里的「**筛选…**」打开筛选器。**不用记语法**，一条条加条件：

```
[ 地形   ▾ ] [ 等于      ▾ ] [ 森林 ▾ ]     [×]
[ 温度   ▾ ] [ 介于…之间 ▾ ] [ 10 ] [ 30 ]  [×]
这些条件的关系：( ● 全部满足   ○ 满足任一条 )   反过来（不满足的行）：[ ]
说明：地形 = 森林 且 温度 ≥ 10 且 ≤ 30
```

- 对话框**最上面**那行先告诉你结果：「**按这些条件会选中 N 格**」；这些格里有的没数据时，
  还会补一句「其中 M 格没有温度」。**它就是按「替换选择」真会出现的结果**（预览和实际是同一段代码）；
- 运算符下拉里是**人话**：`等于` / `不等于` / `属于其中之一` / `介于…之间` / `有 / 没有这个数据`，
  比较大小的仍是 `>` `≥` `<` `≤`；
- 规则有：**地形类型**、**温度范围**、**深度范围**、**生物群系**（按群系精确挑）、
  **生物群系标签**（一次挑一组，例如"所有森林类"）、**有 / 没有某个字段**；
- 运算符下拉**只列这条规则允许的**；值的控件按规则自动变（枚举给下拉、范围给两个数字框）；
- 没填完 / 写错的那一行会**标红并说明原因**，而且**不会被算进选择**（刚加一行不会把选择清空）；
  这时顶部那行会退回「还没有可用的条件 —— 每条条件都要填完整才算数」；
- 下面一行是**人话回显**，用来确认"我到底筛的是什么"；
- 四个按钮加一个，按钮上直接写着**前后格数**（`替换（→37 格）`、`并入（12 → 49 格）`…）：
  - **替换选择**：命中的格成为新的选择；
  - **并入选择** / **移出选择**：并进来 / 拿出去（移出**不是**取反）；
  - **在当前选择内筛**：只在现有的选择里保留命中的格；
  - **按同地形连通扩展**：以当前选择为种子，往**同一种地形**的相邻格扩到整片连通区
    （中间夹着别的地形就不过去）。

筛选器**只改"我在看哪些格"，不改地图数据**，所以不进撤销栈。

## 6. 绘制河流、道路和领域

### 6.1 路径

1. 按 `P`。
2. 在右侧边栏「地图面板」→「工具」里的**路径类型**下拉选一种类型 —— **内置 4 种（河流 / 道路 / 贸易路线 / 边界）排在前面，
   你自己定义的类型排在后面**（见 §6.4）。
3. 逐点点击添加顶点。
4. 双击、按回车或右键结束。
5. 在命名框中输入名称，也可以留空跳过。

河流会使用平滑曲线并支持末端变细；道路、贸易路线和边界使用各自的线型。
下拉旁边画着**当前类型**的色块，下拉里显示的是它的名字；如果地图里的类型在本机没有定义，
它会显示「未知（ID）」而不是悄悄跳回第一个类型（数据仍然照常绘制、原样保留）。

### 6.2 三种几何模式：沿格边 / 逐边 / 穿内部

右侧边栏「地图面板」→「工具」里有三个按钮，**只在「路径」和「区域」工具下出现**：

| 模式 | 效果 | 适合 |
|---|---|---|
| **沿格边** | 落点吸附到网格顶点，顶点之间**自动沿格边走** | 国界、领地边界——先把形状点出来，中间不用管 |
| **逐边** | 每次点击只沿格边**前进一条边**，方向由点击位置决定 | 需要精确到每一条边的描边（点哪个方向就往哪走） |
| **穿内部**（默认） | 线条直接穿过六边形内部，可以斜穿格子；河流仍是平滑曲线 | 河流、道路、随手画的线 |

使用要点：

1. 先选模式，再开始画（换模式会取消正在画的半个形状）。
2. **沿格边**：你点的每个顶点都会被吸附到最近的网格角上，中间自动补上沿边顶点；
   **预览里看到的就是最终形状**（含沿边的走法），不会"松手之后变样"。
3. **逐边**：每次点击**必定**前进一条边 —— 往哪个方向点，就往那条格边走；想拐弯就往侧面点。
   预览只显示"接下来这一条边"。这个模式不会漏点、也不会有"点了没反应"的情况。
   区域结束时（双击/回车），如果还没绕回起点，剩下的闭合回程同样沿格边走。
4. **沿格边 / 逐边都不做平滑**：平滑会把格边抹成曲线，正好毁掉整齐的效果。末端变细与虚线仍然保留。
5. 沿格边时线条会比直线**略长**（六边形的三条边方向相隔 120°，两点之间要"多走再抵消"，
   最坏约 2 倍）—— 这是换取整齐的代价，不是 bug。逐边模式不存在这个问题（每步就是你点的那条边）。
6. 绘制结果里的 `mode` 字段会记住用的是哪种模式（`edge` / `edge-step` / `interior`；
   缺省为 `interior`，因此旧地图不受影响）。

路径也支持可选的 `link` 字段。当前可以直接在地图文档的 JSON 路径对象中填写：

```json
{
  "id": "p1",
  "type": "river",
  "pts": [[0, 0], [100, 100]],
  "width": 8,
  "color": "#4a9fd8",
  "label": "北境商路",
  "link": "Routes/北境商路.md"
}
```

填写后，Base 表格和 Base 缩略图中的路径都会跳转到该笔记；没有 `link` 时，路径会回退到地图文档本身。
路径绘制或路径重命名完成后会弹出“关联路径笔记”输入框，可以直接填写或留空跳过。

### 6.3 区域

1. 按 `R`。
2. 逐点点击至少三个顶点。
3. 双击、按回车或右键结束。
4. 在区域类型下拉里选一种类型（每个选项都带**自己的色块**，所以颜色相近的类型也分得清）。
5. 输入国家或领地名称，也可以留空。

选择模式下双击路径或区域可以改名；右键可以删除。

按 `Esc` 可以取消正在绘制的形状。形状完成后再按 `Esc` 会退出绘制模式。

### 6.4 自定义路径类型与区域类型

内置 4 种路径类型（河流 / 道路 / 贸易路线 / 边界）与 6 种区域类型（王国 / 帝国 / 公国 / 教区 / 荒原 / 海域）
不够用时，可以自己加。**在哪里做哪件事**分两处：

- **新增 / 删除 / 改 ID 定义** → 「**地图定义…**」弹窗（侧栏面板 →「地图定义」→「管理地图定义…」）
  里的「**路径类型**」/「**区域类型**」两组（四组默认收起，点标题展开）；
- **改参数**（颜色 / 线宽 / 虚线…） → 设置 → Project Kaki → 「**新对象默认值**」折叠组里的
  「路径类型」/「区域类型」一节 —— 内置类型与自定义类型的参数都在这里改。

> **为什么这么分**：参数**只影响新画的对象**（已画对象把参数存在地图文件里），所以留在设置页；
> 而定义的**新增 / 删除 / 改 ID** 是「定义」层面的改动，集中进弹窗。
> 另一条不变：**内置类型的名字固定**（不能改），参数可以改 —— 而**自定义类型的名字**在弹窗里改。

**路径类型**每种可调：

| 参数 | 说明 |
|---|---|
| 颜色 | 这条类型的默认颜色 |
| 线宽 / 虚线 | 线宽是世界单位（1–40）；虚线留空 = 实线 |
| 端点 / 连接 | 平头 / 圆头 / 方头，以及尖角 / 圆角 / 斜角；缺省都是「圆头 / 圆角」= 升级前的行为 |

**区域类型**每种可调：

| 参数 | 说明 |
|---|---|
| 填充色 / 不透明度 | 不透明度 0–1 |
| 边框色 / 边框宽 / 边框虚线 | 边框宽 0–40（**0 = 不画边框**）；边框色留空 = **跟随填充色**；边框虚线留空 = 实线 |

新建时填 **ID** 与 **显示名**（与自定义地形、自定义标记是同一套规则）：

- **ID 才是写进地图文件的值**：小写字母开头、`a-z 0-9 _ -`、2–32 字符，`custom:` 前缀由插件自动补上；
- **显示名只是界面文案**（留空就用 ID）：改显示名、甚至删掉一条定义，都**不会**改动你已经画好的路径或区域；
- 上限：**32** 条自定义路径类型、**32** 条自定义区域类型；
- 内置类型的**名字固定**（不能改），但参数可以改。

四条承诺（与自定义地形、自定义标记同一条口径）：

1. **认不出的类型原样保留 + 告警 + 照常绘制** —— 地图文件里写了本机没有定义的 `type`，
   插件把它画成回退样式，**文件里的值一个字符都不改**，绝不会让整条路径或整个区域消失；
2. **改类型参数只影响以后新画的对象** —— 已画好的对象把自己的颜色、线宽等存在地图文件里；
3. **旧地图不会被补字段** —— 升级前画的区域没有 `type`，读取时保持"没有"、写回时也不补，
   图例仍然按颜色显示原来的类型名字；
4. 「**恢复出厂样式**」只把**内置**路径类型与区域类型的参数、以及字体恢复为出厂默认，
   **不会删掉任何自定义定义**。

> 导出侧与画布是**同一套外观**（2026-09-27 起：标记按字形、区域带自己的不透明度与边框）；
> 只有**图片模式的标记**与**地形图片**在导出里回退（见 §5.3 的说明）。

## 7. 把笔记放到地图上

在笔记的 YAML 前置元数据中加入坐标：

```yaml
---
coordinates: [320, -140]
map-type: city
region: 北境王国
---
```

坐标也支持：

```yaml
coordinates: "320, -140"
```

或：

```yaml
coordinates:
  x: 320
  y: -140
```

坐标写错时，Base 会保留这条笔记并显示警告，不会静默丢失。

## 8. 使用 Base 导航

### 8.1 创建 Base

1. 打开命令面板。
2. 运行 **创建地图 Base 文件（表格视图）**。
3. 打开生成的 `.base` 文件。
4. 将视图类型切换为 **地图**。
5. 在视图选项中确认地图文档和坐标属性。

Base 会把以下内容合并到一张表：

- 地图中的地标；
- 地图中的文字标注；
- 地图中的路径；
- 地图中的区域；
- 笔记中的坐标条目。

### 8.2 地图缩略图

地图文档成功加载后，表格上方会出现缩略图。缩略图包含：

- 六边形地形色块；
- 路径；
- 区域（**带它自己的不透明度与边框**，含虚线 —— 与画布上是同一套外观）；
- 地图地标（**按它自己的图标字形画**，不是一律小圆点）；
- 笔记坐标点。

缩略图与 **SVG / PNG 导出共用同一份实现**：所以"缩略图里长什么样"就是"导出后长什么样"。
两处例外都是有意的：**图片模式的标记**在缩略图与导出里回退成它的字形
（**不内联用户库内的图片** —— 导出要能脱离库打开，而库内图片换个环境就失效）；地形图片也只画底色。
**派生的、有上限的**图不在此列：连续场的颜色面就是一张内联 PNG（上限 128 KiB，超了退回矢量）。
导出完成后提示里会写明数据层走了哪条路（"内联栅格（86 KiB）"或"退回矢量"）。

缩略图会跟随 Base 容器宽度变化。地图使用统一的 X/Y 缩放比例，因此容器比例不同时可能出现留白，但地图本身不应被拉伸。

点击缩略图中的路径、区域、文字、地图地标或笔记点，会打开对应文件。地形格没有独立文件，因此不提供单格跳转。

### 9.1 导出时怎么选范围

打开「导出地图…」对话框后，先选**范围**再选**格式**：

- **全部内容**（默认）：和以前一样，把地图上所有东西一起装进一张图；
- **当前视口**：只导你现在**看得见的那一块** —— 先把画布平移/缩放到合适的位置，再导出；
- **某个区域**：从下拉里选一个你画过的区域（例如「北境领」），按它自己的范围导出。

**为什么需要这个**：导出和图例缩略图都是"把全部内容等比缩进画布"，
所以只要有一个**离主体很远的孤立格**，整张图就会被压小（实现时量过的一个例子：同一块
200×200 的区域，按区域导出时占高约 709/1000 px，按全部内容导出只剩约 10/1000 px；
具体比例取决于你地图上离群内容有多远）。
选「当前视口」或「某个区域」就不会再有这个问题。

两点需要知道：

- **按范围导出不会丢内容**：范围外的内容仍然画了，只是落在视野之外被裁掉 ——
  地图文件里一个字节都没变，换回「全部内容」导出，它们就都在；
- **文件名会带上范围**：全部内容不加后缀（老名字不变）、当前视口是 `-视口`、
  按区域是 `-区域名`（名字里的 `/`、`:` 会被换成 `-`；没起过名字的用「未命名区域 N」）。
  重名照旧自动加 `-2`、`-3`。

导出里的**区域外观与标记字形和画布一致**：区域用它自己的不透明度 / 边框色 / 边框宽 / 边框虚线（按导出比例换算），
标记按它自己的图标字形画；**拿不到字形时回退成小圆点，对象绝不会消失**（未知图标名也一样）。

两处**刻意的不一致**（都是"导出文件要能脱离库单独打开"逼出来的）：**图片模式的标记**回退成字形、
**地形图片**只画底色（不内联用户库内的图片 —— 那会让文件巨大）。
派生的小图是例外：连续场的颜色面会内联成 PNG（上限 128 KiB，超了退回矢量），导出提示里会写明走了哪条路。
另外导出**跟着图层开关走**（与画布同一个开关，见 §5.2）：关掉温度层，导出里就没有它。

导出失败时（例如当前环境不支持把 SVG 转成位图），**对话框会留在原地**并给出可读原因，
你可以换个格式再试一次 —— 而且**不会留下一个空文件**，免得你以为导出成功了。

### 9.2 定义文件：把自定义定义带到别的库

你自己定义的地形、标记图标、路径类型、区域类型**只存在插件设置里**（每个库各一份）。
想备份、带到别的库、或分享给别人，用**定义文件**：

1. **导出**：命令 **导出定义文件…（自定义地形/标记/路径类型/区域类型）**，
   或**设置 → Project Kaki → 最下面「定义文件（导入 / 导出）」**里的同名按钮
   （侧栏「文件与导出」组里已经没有它们了 —— 2026-09-29 搬走）；
2. **导入**：命令 **导入定义文件…**，或设置页那一节里的同名按钮；
   从库里挑一份 `.json`，看完确认对话框再决定。

导出：

- 文件写在**库根目录**，名字形如 `project-kaki-definitions-20260925-1130.json`（带日期与时分，便于区分多次导出）；
- **重名绝不覆盖**：自动加 `-2`、`-3`；导完给出一条提示，写明路径与四类的条数；
- **内置类型不进文件**（内置 9 种地形 / 9 种图标 / 4 种路径类型 / 6 种区域类型每个库里都有）——
  所以"内置类型的参数"不会随文件分享，这是取舍，不是遗漏；
- 设置里一条自定义定义都没有时**不会写出文件**（写一个空文件只会让你以为导出成功了）。

导入：

- 候选列表是**库里的 `.json` 文件**；库里一个都没有时会明确提示"先用『导出定义文件…』生成一份"；
- **先算再问**：确认对话框里写明"将新增 N 条（地形 x · 标记 y · 路径类型 z · 区域类型 w）"、
  哪些因为**同 ID** 被跳过（并给出原因）、以及**这份文件里没有哪一段**；
  没有可新增的条目时确认按钮是灰的；
- **只做补充，绝不删东西**：同 ID 的条目保留**你现有的**定义；文件里没有的那一段（例如老文件里没有"区域类型"）
  **不会改动你现有的对应定义**；
- **幂等**：刚导出的文件立刻再导入 = **0 新增**，设置逐字段不变；
- 格式版本**接受 1 与 2**；**比插件支持的版本更高时明确拒绝**并提示升级插件 ——
  宁可拒绝，也不"尽力解析"后告诉你导入成功了；
- 读取失败 / 解析失败 / 打开对话框失败都只给一条可读提示，**且不会改动任何设置**。

3. **三个默认收起的折叠组**：

   - **`数据层`**：温度与深度各自的**色带**（锚点可改值、改色，越界两端各有一个颜色）、**不透明度**、

     **生物群系**不是色带，而是**逐条颜色**（只列地图上出现过的群系，见「生物群系」一节）。
     这一组只管"**怎么看**"，**看不看**仍由「图层」一组决定（两边不会各存一份状态）；
     深度的**相对值**需要先给这张地图设置**海拔标定**，见下面「深度与海拔标定」；
     💡 **同一份参数也在侧栏「地图面板」里**（「数据层参数」一组，默认收起）——
     改色带、调不透明度不必再切到设置页；两处的控件是**同一份代码**，改哪边都一样；
   - **`新对象默认值`**：**路径类型**与**区域类型**各自的**参数**（内置 4 种路径 + 6 种区域，
     以及你自己加的类型）、名称字体族（留空 = 跟随主题）、「恢复出厂样式」
     （一键还原**内置**参数与字体，**不会删掉任何自定义类型定义**）。
     **参数只影响新画的对象** —— 已画好的路径/区域把自己的颜色、线宽等存在地图文件里，改设置不会改动它们。
     这一组底部有一行**指路**：「新增 / 删除 / 改 ID 定义请到「地图定义…」」。

> 都搬进了「地图定义…」弹窗（见下面「地图定义」）。这一页只留**参数默认值**。

> 或命令面板（画布工具条上原来那个「地图层」按钮已移除 —— 它会随地图层一起消失，关掉之后就点不到了）；

### 深度与海拔标定

深度就是**海拔的表示形式**（同一个量）：`0 = 海平面`、正数 = 向下、负数 = 向上，文件里**永远存米**。

- **怎么看**（**插件设置**，换地图不变）：设置页 →「数据层」→「深度 / 海拔的展示单位」，
  可选 **米 / 千米 / 相对值（0–1）**。这只换读法 —— 格上的数值文字与图例刻度一起变，**文件一个字节都不动**；
- **相对值锚在哪**（**地图自己的事实**）：命令面板或侧栏面板 →「**设置海拔标定…**」→
  填**最深深度**与**最高高度**（都是正数，单位米）。它们是**这张地图**的事实，所以写进**地图文件**
  （源码模式里能看到 `"elevation": {...}` 那一段），而不是插件设置。
  弹窗里有一张**换算预览表**：最深点 / 海平面 / 最高点分别在米、千米、相对值下读作什么
  （海平面落在 `最深 / (最深 + 最高)`，**不**强行放到 0.5 —— 一片大海的地图，海平面本来就该偏一侧）；
- **没标定就不猜**：展示单位选「相对值」而地图还没标定时，读数显示「未标定」，
  而不是拿一个编造的尺度凑数；填错一个数也能立刻从读数上看出来；
- **标定可撤销**：保存后 `Ctrl/Cmd+Z` **一次**就回到原来的标定（清空标定也是一次撤销）；
  点「清空标定」= 把文件里那一段删掉（回到"未标定"），与"填 0"是两件不同的事。

开关在「图层」组里的「**深度**」（出厂关着）。色带的出厂值是"高处浅米 → 海平面浅蓝 → 深海深蓝"，
越界两端是**纯白 / 近黑蓝**（不是温度那对纯蓝 / 纯红 —— 那是冷热的体感语言）。

### 每格默认值（"画过的地方整片都有颜色"）

没量过温度的格原来是空白的。命令 / 侧栏面板 →「**设置数据层默认值…**」给温度、深度各填一个数，
那些格就用它上色：

- **它只是兜底**：一格上有真值就用真值，**没有值才用这个数**。所以它是"这张图的基线"
  （这片大陆平均 15 ℃），而不是往你的数据里塞东西 —— **地图文件里的格一个字节都不改**，
  改完**立刻全图生效**；
- **只覆盖"地图上存在的格"**：画过地形的整片区域都会有颜色；从来没画过东西的空白区**仍然不画**
  （那些格不在文件里）；
- **兜底格不写数值文字**：开了"在每个格上写出数值"也不写，数值越界也不写 ——
  它只是基线，不是量出来的数据（不然满屏 15 会让人以为"这格量过"）；
- **留空 = 这一层不兜底**（不是 0 —— `0` 是合法值：摄氏 0 度、海平面）；温度可以填负数；
- 填的不是数字时**保存按钮会禁用**，原因就写在旁边，改一下就能存；
- 写进**地图文件**（源码模式里能看到 `"dataDefaults": {...}` 那一段，与 `elevation` 同级），
  **保存一次 = 一条历史**（`Ctrl/Cmd+Z` 一次回到原样）；点「清空全部」= 把那一段**删掉**
  （文件里连这个键都不留，不是写一个空对象）；
- ⚠️ 用 `＋ / −` 笔刷（见下）时，无值格会**从默认值起算并把结果写进格** ——
  那些格从此**不再跟随**默认值。

### 生物群系（逐格一个分类）

生物群系是**分类**，不是数值：一格一个 ID（文件里写英文字符串，例如 `desert`），
界面上显示的是中文名（「沙漠」）。两者**解耦** —— 改显示名不会动你已经存下的数据。

- **目录 34 条**（地表 18 / 地下 12 / 高空 4），每条**自带颜色**；开关在「图层」组里的
  「**生物群系**」（出厂关着）；
- **画法是逐格纯色**：不做渐变、不插值、不画等值线、也不在格上写数值（分类值之间没有高低，
  一条色带说不通）；
- **没填的格不画**（不是画成某个颜色）—— 与温度 / 深度同一条口径："没有数据"不该被误读成一个读数；
- **认不出的 ID 也看得见**：别的库写的、或你刚把定义删掉的 ID，一律用**中性灰**画出来，
  显示名就是 ID 本身。画布、图例、右上角信息卡**三处是同一个答案**；
- **图例是"逐个群系一行"**（色块 + 中文名 + 格数），不是一条色带；顺序按显示名排，不会因为改一格就重排；
- **配色**：设置页 →「数据层」→「生物群系的逐条颜色」。这里**只列地图上真的出现过的**群系
  （34 条全列会把设置页撑成一面墙），输入框里的灰色提示就是它当前的颜色；
  填一个 `#rrggbb` 就换成你的色，**清空输入框 = 回到目录色**。
  这一项只改**画法**，不进地图文件 —— 换一份分类表 = 换一批默认色，这条仍然成立。

### 用笔刷批量刷数据层

绘制模式下，右侧边栏「地图面板」的「**笔刷**」一节里有一组：**刷什么**（地形 / 温度 / 深度 / 生物群系）
+ **怎么刷** + **值**。选「地形」时它就是你熟悉的那个地形笔刷。

- **温度 / 深度**：先选算法 `＝ ＋ − × ÷`，再填一个数；
- **生物群系**：只有「设为某个群系」（下拉里 34 条 + 你自己加的），也没有数值框 ——
  对分类 ID 做乘法是没有意义的；
- 半径、`[` `]` 调笔刷大小、一笔一条历史，都与地形笔刷完全一样（`Ctrl/Cmd+Z` 一次退回整笔之前）。

三条**不会让你踩坑**的口径（状态条会同时把原因写出来）：

1. **数值框初始是空的**，不预填任何数 —— 笔是你在用的，值也该由你给；
2. **没填 / 没确认时笔刷不生效**：状态条显示「请先填一个数值」这类原因，
   而不是"点了没反应"。填完按**回车**（或点开别处）才算确认；
3. **换层 / 换算法不静默沿用**：数字**留着**（不用重打），但笔刷会**打回未确认**并提示回车 ——
   于是"换到温度层，笔上还带着刚才给深度填的 +200"这种事故不会发生。

无值的格怎么处理（每一格独立判断）：

| 算法 | 有值的格 | 无值的格 |
|---|---|---|
| `＝` 设为 | 写成这个数 | 写成这个数 |
| `＋ / −` | 原来的数加减 | **从「每格默认值」起算**（没有就 0）—— 这一步会把默认值**固化进这一格**，从此它不再跟随默认值 |
| `× / ÷` | 原来的数乘除 | **跳过**（拿"没量过"去乘没有意义） |
| `÷` 且填了 0 | **整笔不生效**（状态条写明"不能除以 0"），也不会写出一个无穷大的数 | 同左 |

### 地图定义

「地图定义…」是四类自定义定义的**唯一住处**（侧栏面板 →「地图定义」→「管理地图定义…」，
或命令面板里的同名命令）。弹窗里四组 —— **地形 / 标记 / 路径类型 / 区域类型** —— 都**默认收起**，
点标题展开。分界线是**"改动会不会波及已画的对象"**：会波及的（地形 / 标记的**定义内容**）属于
「定义」，进弹窗；只影响新画对象的（路径 / 区域类型的**参数**）留在设置页。

- 每组里就是原来设置页那一节的内容，**一个控件都没少**：
  - **地形 / 标记**：每条 = 模式（调色 / 图片，或字形 / 图片）+ 显示名 + 颜色 / 字形 / 图片 +
    显示方式（图片地形）+ **「改 ID…」** + **「删除」**；底部是「新增自定义地形 / 标记」那一行；
  - **路径类型 / 区域类型**：列出内置与自定义类型；**自定义类型**那一行有「改 ID…」与「删除」；
    底部是「新增自定义路径类型 / 区域类型」那一行（含初值：颜色 / 线宽 / 虚线…）。
- **内置类型没有「改 ID / 删除」按钮**：它们的 ID 写死在程序里，改了等于把内置语义改坏。
- **改 ID** 会说清影响面并**改写地图文件**（见 §5.4）；**删除**只说影响面、**不碰地图文件**（见下）。
- **删除定义**的行为：
  - **有地图在用它** → 先弹确认框：「N 张地图里共 M 处引用 `custom:xxx`」+ 逐文件明细 +
    「**这些对象不会被删除，仍留在文件里，只是画成回退样式（未知）**」+「删除的只是这条定义，可随时重建」。
    **没点确认之前一个字节都不写**；取消则什么都不做；
  - **没有任何引用** → 不弹框，直接删掉并给一条提示（没有影响面可说，弹框只会白挡一下）；
  - 两种情况都**不碰地图文件**（与改 ID 不同 —— 删除是安全的，不需要备份）。

### 自定义地形

内置 9 种地形之外，可以加自己的地形类型：侧栏面板 →「地图定义」→「管理地图定义…」→「地形」一组。
每条填 **ID**（小写字母开头、2–32 位，可用数字、下划线、连字符；`custom:` 前缀由插件自动补上）
与**显示名**（留空就用 ID），最多 40 条。两种模式（见上面「地图定义」）：

- **调色**（新建时默认）：颜色自己挑，字形可以**借用内置 9 种之一的字形**，也可以选「通用」；
- **图片**：用一张库内图片当图块（路径可以手打，也可以点「从库中选择…」），
  还能选**显示方式** —— **单格一张**（每个六边形各一张，默认）或
  **整片一张（连通区域）**（连通的同类型格共用一张图，保持比例、只画在连通区域内）；
  图片取不到时回退成这条地形的颜色 + 字形，并在控制台写明原因。

改完设置不用重开画布：绘制模式下的地形按钮就是「内置 9 种在前、你的自定义地形在后」——
自定义地形**不占用数字键** `1`–`9`，用鼠标点选，悬停提示里有完整 ID。
与自定义标记同一条口径：ID 才是写进地图文件的值（`t: "custom:swamp2"`），
**改显示名、甚至删掉定义，都不会改动你已经画好的格子**（数据原样留在文件里，只是画成回退样式）。

还不能：

- **图块与变体**：每种自定义地形目前只有一套视觉（颜色 + 一个借用来的字形，或者一张图片），
  没有同一地形的多个图块，也没有旋转、镜像这类变体；
- **图片进画布以外的地方**：地形图片与**图片模式的标记**只画在画布上 ——
  Base 缩略图与 SVG / PNG 导出里，地形用回退色、标记回退成它的**字形**
  （**不内联用户库内的图片** —— 换台机器/换个环境那路径就失效了；连续场那种派生的、有上限的栅格是例外）。
  **标记的字形本身现在会进导出**（2026-09-27 起），所以"自定义图标在导出里不见了"已经不是问题；
- **温度 / 深度 / 生物群系都已有画布覆盖层**（侧栏「图层」→ 底图一组里打开，出厂都是关的）：
  温度与深度按格上的值染色，越界用色带两端各自的纯色 + 数值（温度出厂纯蓝 / 纯红，深度出厂纯白 / 近黑蓝），
  色带、越界色、不透明度、是否写数值都在「数据层」一组里（设置页与侧栏「数据层参数」同一份控件）；
  打开「显示图例」还会多出一栏色带（有值就有那一栏，刻度文字随深度的展示单位变）。
  **生物群系**是**分类**：逐格纯色、不插值、不写数值，颜色逐条可改，图例**一行一个群系**。
  深度的**展示单位与海拔标定**见上面「深度与海拔标定」；生物群系见上面「生物群系（逐格一个分类）」。
- **连续场（等温线 / 等高线）**：每个字段的「显示方式」可选**连续场** —— 格心值被插值成一张连续的颜色面，
  再从中提出等值线；线上的数字按**工程图的画法**：数字**沿着线走**、把那一段线**真的挖掉**、
  用与线对比的颜色（深色线配白字）。
  **数字沿等值线重复出现**（每隔一段就有一个读数，等高线图就是这么读的）：
  间隔在「数据层」里调 ——「等值线数字的重复间隔」，单位是**格**（出厂 6），**调小当场变密**。
  数字比格心读数**小一档**，两端不贴端头；描边**与字色相反**（白字配深边、深字配浅边），
  所以压在深色场与浅色场上都读得清。
  **大地图上精度有限**：一张图最多采 65536 个点（单边 256），地图越大、每个采样点覆盖的范围越粗 ——
  这是为了让**平移永不重算**（采样结果按"数据 + 显示参数"缓存，与视口无关）而做的取舍；
  "采样上限可调"留到以后。
- **导出里的叠加层**：温度 / 深度 / 生物群系会跟着进 SVG / PNG 导出与 Base 缩略图（**跟着图层开关走**），
  几何与配色和画布是同一份；连续场在导出里是一张内联 PNG，超过 128 KiB 会退回矢量多边形，
  走哪条路会写在导出提示里。
- **还没做**：自定义生物群系的"新增 / 删除 / 改 ID"界面（内置 34 条与逐条改色都已可用）、
  **每格默认值的"一键写进所有格"**（那个可选动作没做）、自定义地形的图块与变体。
  完整的待办与验收口径见 `docs/PLAN.md` §2.1 / §2.2。

后续的图块与变体会沿用现有的稳定 ID（`custom:` 前缀），避免已有地图因资源改名而失效。
